The cached Demo endpoint uses the same `@liria24/analytics/nuxt` server runtime documented in the
[Nuxt integration](/integrations/nuxt): module configuration resolves the Cloudflare resource,
`useServerAnalytics()` creates the adapter with runtime credentials, and `analytics.query()` returns
a provider-independent report. It never returns credentials or a provider-native response.

Local development, preview, and CI use a deterministic fixture when the provider resource or
credentials are absent. The Vue UI renders the same report shape in both paths.
