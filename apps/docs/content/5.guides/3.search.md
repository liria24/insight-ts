title: Search analytics
description: Query organic search performance with explicit calendar and rollup semantics.

The `search` domain describes how a site appears in organic search and how those impressions turn
into visits. The current built-in search Source is Google Search Console Search Analytics.

## Current data model

| Type       | Names                                                                    |
| ---------- | ------------------------------------------------------------------------ |
| Metrics    | `clicks`, `impressions`, `ctr`, `averagePosition`                        |
| Dimensions | `date`, `hour`, `query`, `page`, `country`, `device`, `searchAppearance` |

`clicks` and `impressions` are additive. `ctr` is derived from clicks and impressions.
`averagePosition` is weighted and non-additive, so it is never silently summed across archive
partitions.

## Time series

```ts
const report = await analytics.search.series({
    grain: 'day',
    metrics: ['clicks', 'impressions', 'ctr'],
    range: {
        from: '2026-08-01T00:00:00.000Z',
        to: '2026-08-31T00:00:00.000Z',
    },
})
```

Use a Source-scoped breakdown for search terms, landing pages, countries, devices, or appearances:

```ts
const report = await analytics.source('google-search-console.search-analytics').breakdown({
    dimensions: ['query', 'page'],
    limit: 100,
    metrics: ['clicks', 'impressions', 'ctr', 'averagePosition'],
    range: {
        from: '2026-08-01T00:00:00.000Z',
        to: '2026-08-31T00:00:00.000Z',
    },
})
```

## Calendar and quality

Search Console uses the `America/Los_Angeles` source calendar. The Provider converts half-open
query instants to provider dates and records source and bucket timezones in the report. Top-row
limits and incomplete data remain visible through `meta.quality` and `meta.freshness`.

Daily clicks, impressions, and CTR can be archived. See the [Google Search Console
provider](/providers/google-search-console) for authentication and native interface details.
