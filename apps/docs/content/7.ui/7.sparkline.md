---
title: InsightSparkline
description: Render a compact, accessible SVG trend from a single-metric result.
---

Use `InsightSparkline` beside a stat or in a dense list where the shape of one Metric matters more
than axis labels. It is a native SVG and derives the Metric from `data`.

## Example

::code-preview
:::insight-sparkline{:data='{"data":{"points":[{"time":"2026-08-26T00:00:00.000Z","values":{"pageViews":1240}},{"time":"2026-08-27T00:00:00.000Z","values":{"pageViews":1510}},{"time":"2026-08-28T00:00:00.000Z","values":{"pageViews":1390}}],"values":{"pageViews":4140}},"meta":{"contributions":[],"queriedAt":"2026-08-28T09:00:00.000Z"}}' :height="48" :width="240"}
:::

#code

```vue
<InsightSparkline
    :data="{
        data: {
            points: [
                { time: '2026-08-26T00:00:00.000Z', values: { pageViews: 1240 } },
                { time: '2026-08-27T00:00:00.000Z', values: { pageViews: 1510 } },
                { time: '2026-08-28T00:00:00.000Z', values: { pageViews: 1390 } },
            ],
            values: { pageViews: 4140 },
        },
        meta: {
            queriedAt: '2026-08-28T09:00:00.000Z',
            contributions: [],
        },
    }"
    :height="48"
    :width="240"
/>
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightSparkline } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightSparkline :data="dashboard.visitSeries" :height="40" :width="120" />
</template>
```

Missing points are omitted. The sparkline performs no query, aggregation, smoothing, or History
work; select one Metric in the query.

## Props

| Prop     | Type                                  | Default       |
| -------- | ------------------------------------- | ------------- |
| `data`   | Metric `QueryResult` with time points | required      |
| `width`  | `number`                              | `96`          |
| `height` | `number`                              | `32`          |
| `class`  | class value                           | root SVG only |
| `ui`     | `InsightSparklineUI`                  | —             |

## Customization

```vue
<InsightSparkline
    class="text-primary"
    :data="dashboard.visitSeries"
    :ui="{ path: 'stroke-current [stroke-width:3px]' }"
/>
```

| `ui` key | `data-slot` | Element    |
| -------- | ----------- | ---------- |
| `root`   | `root`      | `<svg>`    |
| `path`   | `path`      | trend path |

The path inherits `--insight-chart-1` for its stroke color. There is no value formatter because the
component does not render a number; provide an `aria-label` on the root when the default metric
name is not sufficient.
