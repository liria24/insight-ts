---
title: InsightLineChart
description: Plot every selected Metric series with proportional time spacing.
---

Use `InsightLineChart` to compare time-series metrics selected together by one Metrics query. It
renders them in query order and preserves gaps between timestamps.

## Example

::code-preview
:::insight-line-chart{:data='{"data":{"points":[{"time":"2026-08-26T00:00:00.000Z","values":{"pageViews":1240}},{"time":"2026-08-27T00:00:00.000Z","values":{"pageViews":1510}},{"time":"2026-08-28T00:00:00.000Z","values":{"pageViews":1390}}],"values":{"pageViews":4140}},"meta":{"contributions":[],"queriedAt":"2026-08-28T09:00:00.000Z"}}' :height="240" title="Traffic"}
:::

#code

```vue
<InsightLineChart
    :data="{
        data: {
            points: [
                { time: '2026-08-26T00:00:00.000Z', values: { pageViews: 1240 } },
                { time: '2026-08-27T00:00:00.000Z', values: { pageViews: 1510 } },
                { time: '2026-08-28T00:00:00.000Z', values: { pageViews: 1390 } },
            ],
            values: { pageViews: 4140 },
        },
        meta: {
            queriedAt: '2026-08-28T09:00:00.000Z',
            contributions: [],
        },
    }"
    :height="240"
    title="Traffic"
/>
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightLineChart } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightLineChart :data="dashboard.trafficSeries" title="Traffic" />
</template>
```

Metric selection belongs to the query. The chart deliberately has no `metrics` prop and does not
aggregate, fetch, or reorder the selected results.

## Props

| Prop       | Type                                   | Default                        |
| ---------- | -------------------------------------- | ------------------------------ |
| `data`     | Metric `QueryResult` with time points  | required                       |
| `title`    | `string`                               | —                              |
| `height`   | `number`                               | `360`                          |
| `colors`   | `readonly string[]`                    | six `--insight-chart-*` colors |
| `smooth`   | `boolean`                              | `false`                        |
| `locale`   | `string`                               | `en-US`                        |
| `timezone` | `local`, `source`, `utc`, or IANA zone | local                          |
| `xAxis`    | `XAxisOptions`                         | —                              |
| `yAxis`    | `YAxisOptions`                         | —                              |
| `class`    | class value                            | root only                      |
| `ui`       | `InsightLineChartUI`                   | —                              |

## Customization

```vue
<InsightLineChart
    :data="dashboard.trafficSeries"
    title="Traffic"
    :x-axis="{ maxTicks: 4, formatter: (date) => date.toLocaleDateString() }"
    :y-axis="{ formatter: (value) => `${value.toLocaleString()} visits` }"
    :ui="{ legend: 'text-xs', plot: 'rounded-lg bg-muted/30 p-3' }"
/>
```

| `ui` key          | `data-slot`        | Element                  |
| ----------------- | ------------------ | ------------------------ |
| `root`            | `root`             | chart section            |
| `header`          | `header`           | title and legend wrapper |
| `title`           | `title`            | heading                  |
| `plot`            | `plot`             | chart and fidelity bands |
| `legend`          | `legend`           | series list              |
| `legendItem`      | `legend-item`      | series item              |
| `legendIndicator` | `legend-indicator` | color marker             |
| `tooltip`         | `tooltip`          | tooltip panel            |
| `tooltipLabel`    | `tooltip-label`    | tooltip time label       |
| `tooltipItem`     | `tooltip-item`     | tooltip series value     |
| `notices`         | `notices`          | quality message          |
| `empty`           | `empty`            | empty state              |

The chart inherits `--insight-text`, `--insight-text-muted`, `--insight-text-highlighted`,
`--insight-border`, `--insight-background`, `--insight-chart-axis`, `--insight-chart-grid`, and
`--insight-chart-1` through `--insight-chart-6`. Set them on the root `class` with your CSS.

`xAxis.formatter` receives a `Date`; `yAxis.formatter` receives a number. `colors` changes series
colors without exposing the private chart renderer.

::code-collapse{name="axis options"}

```ts
const xAxis = { maxTicks: 6, formatter: (date: Date) => date.toLocaleDateString('en-US') }
const yAxis = {
    domain: { min: 0 },
    formatter: (value: number) => `${value.toLocaleString()} visits`,
}
```

::

## Slots

| Slot      | Receives                         | Replaces        |
| --------- | -------------------------------- | --------------- |
| `title`   | `{ title }`                      | title markup    |
| `legend`  | `{ series }`                     | legend markup   |
| `tooltip` | `{ label, point, values }`       | tooltip markup  |
| `notices` | `{ messages, notices, quality }` | quality message |
| `empty`   | `{ message }`                    | empty state     |
