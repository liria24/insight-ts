---
title: InsightBarChart
description: Compare the Metric in a single-metric result across one selected dimension.
---

Use `InsightBarChart` for a compact ranked comparison such as page views by path or revenue by
plan. The Metric comes from `data`; `dimension` selects the returned dimension to display.

## Example

::code-preview
:::insight-bar-chart{:data='{"data":{"points":[{"dimensions":{"country":"Japan"},"values":{"pageViews":1240}},{"dimensions":{"country":"United States"},"values":{"pageViews":1510}},{"dimensions":{"country":"Germany"},"values":{"pageViews":1390}}],"values":{"pageViews":4140}},"meta":{"contributions":[],"queriedAt":"2026-08-28T09:00:00.000Z"}}' dimension="country" :height="180"}
:::

#code

```vue
<InsightBarChart
    :data="{
        data: {
            points: [
                { dimensions: { country: 'Japan' }, values: { pageViews: 1240 } },
                { dimensions: { country: 'United States' }, values: { pageViews: 1510 } },
                { dimensions: { country: 'Germany' }, values: { pageViews: 1390 } },
            ],
            values: { pageViews: 4140 },
        },
        meta: {
            queriedAt: '2026-08-28T09:00:00.000Z',
            contributions: [],
        },
    }"
    dimension="country"
    :height="180"
/>
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightBarChart } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightBarChart :data="dashboard.topPages" dimension="path" />
</template>
```

The component uses the points returned for the result's Metric. It does not sort, fetch, aggregate,
or add a limit; select one Metric and make those choices in the query.

## Props

| Prop        | Type                                       | Default       |
| ----------- | ------------------------------------------ | ------------- |
| `data`      | Metric `QueryResult` with dimension points | required      |
| `dimension` | selected dimension key                     | required      |
| `height`    | `number`                                   | `240`         |
| `formatter` | `(value: number) => string`                | locale number |
| `locale`    | `string`                                   | `en-US`       |
| `emptyText` | `string`                                   | `No data`     |
| `class`     | class value                                | root only     |
| `ui`        | `InsightBarChartUI`                        | —             |

## Customization

```vue
<InsightBarChart
    :data="dashboard.topPages"
    dimension="path"
    :formatter="(value) => new Intl.NumberFormat('en', { notation: 'compact' }).format(value)"
    :ui="{ bar: 'bg-primary', label: 'font-medium', track: 'bg-muted' }"
/>
```

| `ui` key | `data-slot` | Element         |
| -------- | ----------- | --------------- |
| `root`   | `root`      | chart wrapper   |
| `list`   | `list`      | ordered list    |
| `item`   | `item`      | comparison row  |
| `label`  | `label`     | dimension value |
| `track`  | `track`     | bar track       |
| `bar`    | `bar`       | value bar       |
| `value`  | `value`     | formatted value |
| `empty`  | `empty`     | empty state     |

The bar chart inherits `--insight-text`, `--insight-text-muted`, `--insight-chart-grid`, and
`--insight-chart-1`. `formatter` owns the displayed value; `locale` applies only to the default
number formatter.
