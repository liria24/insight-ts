Use the Google Search Console Provider for typed Search Analytics Metrics. Your host supplies an
access-token callback; Insight.ts neither stores OAuth credentials nor creates login routes.

## Setup and query

```ts
import { createInsight } from 'insight-ts'
import { googleSearchConsole } from 'insight-ts/google-search-console'

const insight = createInsight({
    providers: [
        googleSearchConsole({
            auth: { getAccessToken },
            property: 'sc-domain:example.com',
        }),
    ],
})

const result = await insight.query((q) => ({
    search: q.metrics({
        metrics: ['clicks', 'impressions', 'ctr', 'averagePosition'],
        dimensions: ['query', 'page'],
        time,
        where: {
            page: { contains: '/docs' },
        },
    }),
}))
```

## Supported API

Metrics are `clicks`, `impressions`, `ctr`, and `averagePosition`. Supported dimensions are date,
hour, query, page, country, device, and search appearance. Adapter typing prevents unsupported
filters, Metrics, and dimension combinations before network I/O.

## Constraints

::caution
Search Analytics returns top rows rather than a guaranteed complete set. Results are always marked
partial, and incomplete dates, range expansion, pagination effects, and Pacific calendar boundaries
remain visible in metadata and quality warnings.
::

Insight.ts handles native pagination internally. Use the canonical query `limit` when the query
itself should return fewer rows.

## Advanced execution settings

Normal applications should keep the conservative default execution limit. If a measured workload
requires a different hard ceiling, configure it explicitly:

```ts
googleSearchConsole({
    advanced: { maxRows: 500_000 },
    auth: { getAccessToken },
    property: 'sc-domain:example.com',
})
```

Reaching this ceiling marks the result partial and adds an `execution-limit` quality warning. The
advanced setting controls Provider work; it does not change canonical query semantics.

`ctr` is a derived ratio. `averagePosition` is not additive and is never silently rolled up.
