Use `insight-ts/nuxt` to configure built-in Providers in `nuxt.config.ts` and access a typed
server-only `useInsight()`. The module composes the Nitro integration; it does not import Vue UI or
serialize credentials.

## Setup

::code-tree{default-value="nuxt.config.ts" expand-all}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['insight-ts/nuxt'],
    insight: {
        providers: {
            cloudflare: { webAnalytics: true },
        },
    },
    runtimeConfig: {
        cloudflare: {
            accountId: '',
            apiToken: '',
            host: 'example.com',
            siteTag: '',
        },
    },
})
```

```ts [server/insight.config.ts]
import { defineNuxtInsightConfig } from 'insight-ts/nuxt'

export default defineNuxtInsightConfig({
    providers: [],
})
```

::

## Query on the server

```ts
export default defineEventHandler((event) =>
    useInsight().query(
        (q) => ({
            traffic: q.metrics({
                metrics: ['pageViews', 'visits'],
                time: { from, to, grain: 'day' },
            }),
        }),
        { signal: event.request.signal },
    ),
)
```

## History

Add `insight.history` when the app needs History. Optional `capabilities` and `scopes` select public
canonical boundaries; omitting them enables every materializable adapter. Configure the required
`insight` storage mount in `nitro.storage` or `nitro.devStorage`; no implicit in-memory fallback
exists. Set `insight.history.tasks: true` only when Nitro experimental tasks are also enabled.

```ts
export default defineNuxtConfig({
    insight: {
        history: {
            capabilities: ['metrics', 'logs', 'traces'],
            tasks: true,
        },
    },
})
```

::warning
Provider credentials belong in top-level private `runtimeConfig.<provider>` keys, such as
`runtimeConfig.cloudflare`. Never place them under `runtimeConfig.insight` or client runtime config.
::

## What the module does not do

It does not auto-register Vue components, scan UI source, inject UI CSS, enable Vapor, or provide a
browser event relay. Import `insight-ts/vue/ui` in the application that renders Metric results.
