# API

The package keeps provider and runtime code behind explicit subpath exports.

| Import                                     | Purpose                                          |
| ------------------------------------------ | ------------------------------------------------ |
| `@liria24/analytics`                       | Core configuration, queries, reports, and errors |
| `@liria24/analytics/browser`               | Typed browser event client                       |
| `@liria24/analytics/cloudflare`            | Cloudflare Web Analytics and Analytics Engine    |
| `@liria24/analytics/google-search-console` | Google Search Console Search Analytics           |
| `@liria24/analytics/nuxt`                  | Nuxt module and integration types                |
| `@liria24/analytics/nuxt/runtime`          | Nitro event relay and server-config helpers      |
| `@liria24/analytics/vue`                   | Provide/inject helpers for the browser client    |

## Browser events

```ts
import { createBrowserAnalytics } from '@liria24/analytics/browser'

interface Events {
    signup: { plan: 'free' | 'pro' }
}

const analytics = createBrowserAnalytics<Events>()
analytics.track('signup', { plan: 'pro' })
await analytics.flush()
```

The browser client only sends bounded batches to its same-origin relay. It has no persistent
cache, cross-origin transport, or automatic query endpoint.
