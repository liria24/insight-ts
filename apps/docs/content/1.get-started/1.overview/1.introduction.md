title: Introduction
description: Query canonical Metrics, Logs, and Traces across logical Scopes.
---

Insight.ts is a TypeScript SDK for querying data across services without exposing their topology in
consumer code. You select canonical capabilities and keep sampling, partiality, and freshness
visible.

```ts
const [traffic, logs, traces] = await Promise.all([
    insight.metrics(trafficQuery),
    insight.logs({ time, limit: 20 }),
    insight.traces({ time, where: { status: 'error' } }),
])
```

Start with one Scope. Add History, events, or UI only when your application needs
them.
