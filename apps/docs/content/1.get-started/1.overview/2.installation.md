---
title: Installation
description: Install Insight.ts with the package manager your project already uses.
---

Install the core package first. Provider, History, browser, and UI entrypoints are all exported from
that package and are only loaded when you import them.

## Install

::code-group

```sh [Bun]
bun add insight-ts
```

```sh [pnpm]
pnpm add insight-ts
```

```sh [npm]
npm install insight-ts
```

```sh [Yarn]
yarn add insight-ts
```

```sh [vlt]
vlt add insight-ts
```

::

## Create a client

::steps

### Import Core and a Provider

```ts
import { createInsight } from 'insight-ts'
import { cloudflare } from 'insight-ts/cloudflare'
```

### Register at least one Provider

A Provider supplies internal adapters to the Scope. The next page creates a complete Cloudflare
example.

### Query a capability

```ts
const result = await insight.query((q) => ({
    traffic: q.metrics(query),
}))
```

::

## Optional entrypoints

| Need                                       | Import               |
| ------------------------------------------ | -------------------- |
| typed Metrics and filters                  | `insight-ts/metrics` |
| canonical Logs                             | `insight-ts/logs`    |
| canonical Traces                           | `insight-ts/traces`  |
| historical materialization                 | `insight-ts/history` |
| browser event client                       | `insight-ts/browser` |
| Vue provide/inject for that browser client | `insight-ts/vue`     |
| Vue Metric components                      | `insight-ts/vue/ui`  |
| Nitro History storage                      | `insight-ts/nitro`   |
| Nuxt module                                | `insight-ts/nuxt`    |

::note
Importing `insight-ts/vue/ui` loads its base CSS and private chart renderer. Core, Providers,
Nitro, Nuxt, and `insight-ts/vue` do not load UI assets.
::
