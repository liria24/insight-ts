---
title: Traffic metrics
description: Query Cloudflare traffic, breakdowns, and an explicitly application-owned recent KPI.
---

This pattern returns a traffic series, a page breakdown, and a separate recent visits query. Each
result keeps its own range and quality metadata.

```ts
const [series, pages, recent] = await Promise.all([
    insight.metrics({
        metrics: ['pageViews', 'visits'],
        time: { ...range, grain: 'day' },
    }),
    insight.metrics({
        dimensions: ['path'],
        limit: 20,
        metrics: ['pageViews'],
        time: range,
    }),
    insight.metrics({
        metrics: ['visits'],
        time: recentFiveMinutes,
    }),
])

const online = Math.round(recent.aggregate.visits ?? 0)
```

::caution
`online` is an application KPI based on a short visits range, not a Cloudflare active-user Metric.
Keep its label and range explicit, and do not use it as a History rollup.
::

Use `InsightAreaChart` for `series`, `InsightBreakdownTable` or `InsightBarChart` for `pages`, and
`InsightStat` for the current summary. Pass each result's quality to `InsightQualityNotice` when it
needs a dedicated location.
