title: Results and quality
description: Read canonical data, contribution Quality, pagination, and History Fidelity correctly.
---

Every capability returns plain serializable `data` and a shared metadata envelope.

```ts
interface QueryResult<TData, TMeta extends object = {}> {
    data: TData
    meta: TMeta & {
        contributions: readonly { fields?: readonly string[]; quality?: QueryQuality }[]
        pagination?: { next?: InsightCursor }
        quality?: QueryQuality
        queriedAt: string
    }
}
```

## Metric results

Metrics use scalar `data.values` and optional row-major `data.points`. Each point shares its `time`
and `dimensions` across selected Metric values. Definitions carry semantic units, structured
aggregation, and rollup; UI code owns presentation formatting.

## Read metadata at its level

- `meta.contributions` preserves field-level or per-contributor Quality after merging.
- `meta.quality` is the conservative aggregate for approximation, partiality, sampling,
  thresholding, and warnings.
- `meta.pagination.next` is an opaque continuation for only that result.
- History Fidelity is range-scoped and remains distinct from Provider Quality.

::tip
Render quality close to the value it qualifies. Do not turn a sampling warning into a zero, a
missing value, or an apparently exact aggregate.
::
