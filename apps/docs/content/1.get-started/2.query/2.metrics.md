---
title: Metrics
description: Query canonical values, time series, and dimensional breakdowns.
---

Metrics describe named numeric measurements independently of a Provider's native API. Select the
values you need and add dimensions only when the result must be broken down.

```ts
const { traffic } = await insight.query((q) => ({
    traffic: q.metrics({
        dimensions: ['country'],
        metrics: ['pageViews', 'visits'],
        time: { from, to, grain: 'day' },
    }),
}))
```

`data.values` contains totals. `data.points` contains row-major time or dimension points when the
query requests them. Metric definitions retain units, aggregation, and safe rollup semantics;
unsafe non-additive History rollups fail explicitly.
