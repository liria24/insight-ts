---
title: Metrics
description: Query canonical values, time series, and dimensional breakdowns.
---

Metrics describe named numeric measurements independently of a Provider's native API. Select the
values you need and add dimensions only when the result must be broken down.

```ts
const traffic = await insight.metrics({
    dimensions: ['country'],
    metrics: ['pageViews', 'visits'],
    time: { from, to, grain: 'day' },
})
```

`aggregate` contains the query-wide aggregation. Optional `rows` contain grouped aggregates for the
requested time grain or dimensions; each row keeps Metric values under `row.values`. Metric
definitions retain units, aggregation, and safe rollup semantics; unsafe non-additive History
rollups fail explicitly.
