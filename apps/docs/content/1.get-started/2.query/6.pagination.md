---
title: Pagination
description: Continue one canonical result without rebuilding its query.
---

Pagination belongs to one QueryResult. Independent capability calls do not share or advance
pagination state.

```ts
const [overview, errors] = await Promise.all([
    insight.metrics({ metrics: ['requests'], time }),
    insight.logs({ time, limit: 32 }),
])

const second = errors.meta.pagination ? await insight.next(errors) : undefined
```

Only the `errors` result continues, so `overview` does not execute again. You do not repeat its time,
filters, limit, or other inputs. QueryResult stays plain serializable data; it never contains an
executable `next()` method.

Continuation also works after normal serialization:

```ts
const restored = JSON.parse(JSON.stringify(errors))
const second = await insight.next(restored)
```

## Opaque continuation

`meta.pagination.next` is private continuation state. Do not parse, modify, or substitute a
Provider-native token for it. It contains a bounded logical binding and native position, without Log
or Trace records. At the terminal page, `meta.pagination` is omitted and `insight.next(result)` fails
with `INVALID_QUERY`.

Use the same scoped client that produced a result:

```ts
const production = insight.scope('production')
const first = await production.logs({ time, limit: 32 })
const second = await production.next(first)
```

## Adapter behavior

Single-adapter Logs and Traces continue directly from the adapter's native position. The adapter
must honor the requested limit and provide stable pagination for the fixed time range. Provider-side
changes inside that range follow the Provider's consistency model.

Multi-adapter Logs and Traces still merge and deduplicate terminal results. If any contributing
adapter requires another page, the query fails with `UNSUPPORTED_OPERATION`; Insight.ts does not
carry result records or an ever-growing emitted-ID set inside the continuation.

The same QueryResult pagination envelope is used for live Provider reads and History-backed reads.
Provider and repository cursor formats remain internal.
