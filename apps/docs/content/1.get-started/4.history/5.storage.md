---
title: Storage
description: Implement the small generic repository contract or use Nitro Storage.
---

A History repository implements only `coverage`, bounded `read`, `replace`, and `delete`. It stores
opaque canonical segments and does not plan queries, aggregate values, or reduce data.

The Nitro integration mounts this contract on `nitro.storage.insight` or
`nitro.devStorage.insight`. Its private v3 layout indexes exact ranges per Scope, capability, and
adapter, so narrow reads enumerate only overlapping partition prefixes. Repository cursors remain
opaque and deterministic across partitions.
