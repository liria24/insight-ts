---
title: History
description: Preserve canonical Metrics, Logs, and Traces beyond Provider retention.
---

Use History when native Provider retention is shorter than the range your product needs. The same
workflow preserves any configured canonical capability that declares a
materializer. Missing or provisional intervals are filled through normal Provider execution.

```ts
import { createHistory } from 'insight-ts/history'

const insight = createInsight({
    providers,
    history: createHistory({
        repository,
        capabilities: ['metrics', 'logs', 'traces'],
        // Optional when all configured Scopes should be preserved.
        scopes: ['production'],
    }),
})

await insight.history.sync({
    range: { from: '2026-01-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

Omit `capabilities` and `scopes` to enable every materializable adapter. `sync()` accepts the same
optional selection to narrow one run without exposing Provider adapter IDs.

## Materialization and pagination

Canonical capability adapters own data-specific capture and reconstruction. Metrics retain safe
aggregation and ratio rules; Logs and Traces retain stable IDs and ordering. History drains every
native continuation before marking a range complete. Later event-like queries use bounded
repository reads and continue through `insight.next(result)` like live queries.

The Engine owns gap slicing, deterministic identity, stable and provisional coverage, and
lifecycle. A repository implements `coverage`, bounded `read`, `replace`, and `delete`.

## Coverage and lifecycle

An empty segment means a completed capture found no matching data. Provider `QueryQuality` is
preserved independently from refreshability: a stable partial result remains covered, while
`meta.freshness.provisionalFrom` keeps only the changing suffix refreshable.

Use `insight.history.expire({ before })` to delete aged ranges explicitly.

::caution
History is not a cache. Queries a capability materializer cannot represent execute live. Unsafe
percentiles and other non-additive values make the whole Metric query execute live when any selected
projection would require an unsafe rollup. A repository may compress losslessly but must preserve
the exact canonical data.
::
