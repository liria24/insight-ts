---
title: Events
description: Type application events while keeping provider transport and trust boundaries native.
---

Declare an application event schema on the Insight client, then track the validated event on the
server.

```ts
const insight = createInsight({
    events: { signup: { properties: { plan: ['free', 'pro'] } } },
    providers,
})

await insight.track('signup', { plan: 'pro' })
```

Providers own transport, sessions, identity, consent, attribution, and native batching. Insight.ts
owns the event name and property contract, Scope routing, and shared delivery behavior.
