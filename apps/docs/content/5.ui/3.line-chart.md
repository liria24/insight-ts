---
title: AnalyticsLineChart
description: Render provider-independent analytics series with stable axes, dates, legend, and tooltip.
---

`AnalyticsLineChart` renders a series report through a small Analytics SDK API. The underlying
renderer handles plotting, axes, grid, and pointer calculations; its configuration types are not
part of the public contract.

## Usage

```vue
<AnalyticsLineChart :report="report" :metrics="['pageViews', 'visits']" title="Traffic" />
```

### Selecting metrics

`metrics` preserves the requested order and ignores metrics with no finite values. When omitted,
all finite metrics present in the report are shown.

### Height

The default height is `360` pixels. The chart container applies `width`, `height`, and `min-height`
explicitly, so its layout remains stable before and after client mounting.

```vue
<AnalyticsLineChart :height="420" :report="report" />
```

### Smoothing

```vue
<AnalyticsLineChart smooth :report="report" />
```

### Colors

Colors map to selected metrics in order and repeat when needed:

```vue
<AnalyticsLineChart :colors="['#2563eb', '#16a34a']" :report="report" />
```

## X axis

Raw ISO timestamps are never the default axis labels. Formatting follows the report grain:

| Grain            | Example    |
| ---------------- | ---------- |
| `minute`, `hour` | `14:00`    |
| `day`            | `Aug 23`   |
| `week`           | `Aug 17`   |
| `month`          | `Aug 2026` |
| `year`           | `2026`     |

At most six labels are shown by default. The first and last ticks remain available as the labels
are thinned.

```vue
<AnalyticsLineChart
    :report="report"
    :x-axis="{
        maxTicks: 4,
        formatter: (date, context) =>
            new Intl.DateTimeFormat(context.locale, {
                month: 'numeric',
                day: 'numeric',
                timeZone: context.timezone === 'local' ? undefined : context.timezone,
            }).format(date),
    }"
/>
```

## Y axis

Automatic domains add proportional padding. Constant series receive a minimum span of roughly 5%
of the value or `1`, whichever is larger. Non-negative data is not padded below zero.

```vue
<AnalyticsLineChart
    :report="report"
    :y-axis="{
        includeZero: true,
        padding: 0.08,
        formatter: (value) => value.toLocaleString(),
    }"
/>
```

`min` and `max` provide explicit renderer-independent bounds.

## Timezone

Timezone resolution is deterministic:

1. explicit `timezone` prop;
2. `report.meta.temporal.bucketTimezone`;
3. `report.meta.temporal.sourceTimezone`;
4. `UTC`.

Undefined never means the browser timezone. Use `timezone="local"` to opt in to the browser's local
timezone.

```vue
<AnalyticsLineChart :report="report" timezone="Asia/Tokyo" />
```

Provider adapters set temporal metadata; the Vue component never branches on provider names.

## Locale

`locale` controls default date and metric formatting:

```vue
<AnalyticsLineChart locale="ja-JP" :report="report" />
```

## Legend

The legend is Analytics SDK markup and can be styled or replaced without renderer options:

```vue
<AnalyticsLineChart :report="report">
    <template #legend="{ series, ui }">
        <ul :class="ui.legend">
            <li v-for="item in series" :key="item.metric">
                {{ item.name }}
            </li>
        </ul>
    </template>
</AnalyticsLineChart>
```

## Tooltip

The tooltip receives provider-independent point and metric values:

```vue
<AnalyticsLineChart :report="report">
    <template #tooltip="{ label, values, ui }">
        <div :class="ui.tooltip">
            <strong :class="ui.tooltipLabel">{{ label }}</strong>
            <p v-for="item in values" :key="item.metric" :class="ui.tooltipValue">
                {{ item.name }}: {{ item.formatted }}
            </p>
        </div>
    </template>
</AnalyticsLineChart>
```

## Styling with `ui`

```vue
<AnalyticsLineChart
    :report="report"
    :ui="{
        title: 'text-sm font-semibold',
        legend: 'flex gap-3 text-xs text-muted',
        chart: 'min-h-80',
    }"
/>
```

### UI slots

| Key               | Target                             |
| ----------------- | ---------------------------------- |
| `root`            | Component root                     |
| `header`          | Title and legend header            |
| `title`           | Chart title                        |
| `chart`           | Fixed-height chart container       |
| `legend`          | Legend list                        |
| `legendItem`      | Legend item                        |
| `legendIndicator` | Series color indicator             |
| `tooltip`         | Tooltip surface                    |
| `tooltipLabel`    | Tooltip date label                 |
| `tooltipValue`    | Tooltip metric row                 |
| `quality`         | Report quality message             |
| `empty`           | Empty or incompatible report state |

## CSS variables

Use `--analytics-chart-axis` and `--analytics-chart-grid` for SVG elements. Text, borders, and
tooltip surfaces use the shared semantic variables documented in [Styling](/ui/styling).

## Custom `#chart` slot

The `chart` slot can replace the internal renderer while keeping Analytics SDK transformation:

```vue
<AnalyticsLineChart :report="report">
    <template #chart="{ labels, points, series, yDomain, ui }">
        <MyRenderer
            :class="ui.chart"
            :labels="labels"
            :points="points"
            :series="series"
            :y-domain="yDomain"
        />
    </template>
</AnalyticsLineChart>
```

No renderer-specific config or dataset type is exposed.

## Slots

| Slot      | Props                                                                         | Default behavior                  |
| --------- | ----------------------------------------------------------------------------- | --------------------------------- |
| `title`   | `title`, `ui`                                                                 | Renders the title                 |
| `legend`  | `series`, `ui`                                                                | Renders the SDK legend            |
| `chart`   | `labels`, `metrics`, `points`, `series`, `times`, `timezone`, `yDomain`, `ui` | Renders the chart                 |
| `tooltip` | `label`, `point`, `values`, `ui`                                              | Renders the SDK tooltip           |
| `quality` | `messages`, `quality`, `ui`                                                   | Renders report quality warnings   |
| `empty`   | `reason`, `ui`                                                                | Renders an accessible empty state |

## API

| Prop       | Type                    | Default           |
| ---------- | ----------------------- | ----------------- |
| `report`   | `AnalyticsReport`       | required          |
| `metrics`  | `readonly string[]`     | all finite        |
| `title`    | `string`                | —                 |
| `height`   | `number`                | `360`             |
| `smooth`   | `boolean`               | `false`           |
| `colors`   | `readonly string[]`     | SDK palette       |
| `locale`   | `string`                | `en-US`           |
| `timezone` | `string \| 'local'`     | report/UTC        |
| `xAxis`    | `AnalyticsXAxisOptions` | `{ maxTicks: 6 }` |
| `yAxis`    | `AnalyticsYAxisOptions` | auto domain       |
| `class`    | `AnalyticsUIClass`      | —                 |
| `ui`       | `AnalyticsLineChartUI`  | —                 |
