---
title: AnalyticsLineChart
description: Render analytics series as an SSR line chart with proportional time spacing.
---

`AnalyticsLineChart` accepts an `AnalyticsSeriesReport`. TanStack Charts renders the SVG
internally; renderer marks, scales, and types are not public API.

## Live example

::analytics-ui-docs-example{kind="line"}
::

```vue
<AnalyticsLineChart :report="report" :metrics="['pageViews', 'visits']" title="Traffic" />
```

Metrics retain the requested order and unknown or entirely empty metrics are ignored. Timestamps
use a continuous time domain, so missing dates remain visible as a wider gap instead of appearing
as adjacent categories.

## Rendering

`smooth="false"` uses linear segments; `smooth` uses a monotone curve. `height` defaults to
`360`. SSR emits the complete SVG at a deterministic initial width, a fixed-height plot region,
and an exact-value semantic table containing timestamp, metric, and value. Hydration enhances the
same markup with focus and tooltip behavior.

```vue
<AnalyticsLineChart smooth :height="420" :colors="['#2563eb', '#16a34a']" :report="report" />
```

## Axes, locale, and timezone

Timezone resolution is explicit prop, bucket timezone, source timezone, then `UTC`. Use
`timezone="local"` only when browser-local formatting is intended.

```vue
<AnalyticsLineChart
    locale="ja-JP"
    timezone="Asia/Tokyo"
    :report="report"
    :x-axis="{ maxTicks: 4, formatter: (date) => `${date.getUTCMonth() + 1}/${date.getUTCDate()}` }"
    :y-axis="{ includeZero: true, min: 0, formatter: (value) => `${value.toLocaleString()}件` }"
/>
```

Automatic Y domains add proportional padding and keep non-negative data at or above zero. `min`
and `max` provide renderer-independent explicit bounds.

## UI and slots

Chart `ui` keys are `root`, `header`, `title`, `plot`, `legend`, `legendItem`,
`legendIndicator`, `tooltip`, `tooltipLabel`, `tooltipItem`, `quality`, and `empty`.

```vue
<AnalyticsLineChart :report="report">
    <template #legend="{ series }">
        <ul><li v-for="item in series" :key="item.metric">{{ item.name }}</li></ul>
    </template>
    <template #tooltip="{ label, values }">
        <aside><strong>{{ label }}</strong><p v-for="item in values" :key="item.metric">{{ item.name }}: {{ item.formatted }}</p></aside>
    </template>
</AnalyticsLineChart>
```

Semantic slots are `title`, `legend`, `tooltip`, `quality`, and `empty`. The renderer-replacement
`#chart` slot does not exist; build a custom renderer from `AnalyticsSeriesReport` or the
framework-independent `@liria24/analytics/presentation` model when needed.

## API

| Prop       | Type                    | Default           |
| ---------- | ----------------------- | ----------------- |
| `report`   | `AnalyticsSeriesReport` | required          |
| `metrics`  | `readonly string[]`     | all finite        |
| `title`    | `string`                | —                 |
| `height`   | `number`                | `360`             |
| `smooth`   | `boolean`               | `false`           |
| `colors`   | `readonly string[]`     | SDK palette       |
| `locale`   | `string`                | `en-US`           |
| `timezone` | `string \| 'local'`     | report/UTC        |
| `xAxis`    | `AnalyticsXAxisOptions` | `{ maxTicks: 6 }` |
| `yAxis`    | `AnalyticsYAxisOptions` | automatic         |
| `class`    | `AnalyticsUIClass`      | —                 |
| `ui`       | `AnalyticsLineChartUI`  | —                 |
