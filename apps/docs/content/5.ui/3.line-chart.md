---
title: InsightLineChart
description: Render all selected Metric series with proportional time spacing.
---

::insight-ui-docs-example{kind="line"}
::

```vue
<InsightLineChart :data="dashboard.trafficSeries" title="Traffic" />
```

The Source query already selected metrics. The chart renders every metric in `data` insertion order
and deliberately has no `metrics` prop. `xAxis` and `yAxis` own display formatting and domains.
TanStack Charts remains a private SSR-capable renderer.
