Insight.ts Vue UI follows the semantic-slot approach used by Nuxt UI, without depending on Nuxt
UI, Tailwind CSS, or a class-merging runtime.

## Live example

::insight-ui-docs-example{kind="styling"}
::

The UI entry imports its base CSS automatically:

```ts
import { InsightAreaChart } from 'insight-ts/vue/ui'
```

Use the explicit `insight-ts/vue/ui/style.css` export only when a build tool requires a
separate stylesheet entry.

## Class contract

`class` styles the root. `ui` styles default markup by semantic purpose:

```vue
<InsightAreaChart
    class="rounded-lg border p-4"
    :report="report"
    :ui="{ title: 'font-semibold', legend: ['text-xs', 'gap-3'], plot: 'mt-4' }"
/>
```

Public class values are deliberately framework-neutral:

```ts
type InsightUIClass = string | readonly string[]
```

Vue class-object syntax is not part of the contract. Chart keys include `root`, `header`,
`title`, `plot`, `legend`, `legendItem`, `legendIndicator`, `tooltip`, `tooltipLabel`,
`tooltipItem`, `notices`, and `empty`. Table keys use semantic names such as `table`, `header`,
`body`, `row`, `headerCell`, and `cell` rather than DOM tag names.

## Slots

Slots replace markup; `ui` styles the default markup. Slot props therefore contain report data,
not the resolved `ui` object:

```vue
<InsightStat :report="report" metric="pageViews">
    <template #value="{ formatted, value }">
        <strong class="custom-value" :data-value="value">{{ formatted }}</strong>
    </template>
</InsightStat>
```

## Semantic CSS variables

Defaults are owned by the SDK and include dark-mode values. They do not implicitly fall back to
Nuxt UI variables.

| Variable                                  | Purpose                        |
| ----------------------------------------- | ------------------------------ |
| `--insight-text`                          | Default text                   |
| `--insight-text-muted`                    | Secondary text and axes        |
| `--insight-text-highlighted`              | Titles and emphasized values   |
| `--insight-border`                        | Borders and grid               |
| `--insight-background`                    | Tooltip and surface background |
| `--insight-chart-axis`                    | Axis labels                    |
| `--insight-chart-grid`                    | Grid lines                     |
| `--insight-chart-1` … `--insight-chart-6` | Series colors                  |

Override variables on the component or an ancestor. A Nuxt UI color mapping can be added by the
application as an optional preset:

```css
.insight-panel {
    --insight-text-muted: var(--ui-text-muted);
    --insight-border: var(--ui-border);
    --insight-chart-grid: var(--ui-border-muted);
}
```

`notices` receives semantic Provider Quality and range-scoped History Fidelity notices plus their
default-formatted messages. Override the slot to localize or restructure them without merging the
underlying metadata.
