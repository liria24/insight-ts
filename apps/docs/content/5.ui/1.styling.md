Analytics Vue UI follows the semantic-slot approach used by Nuxt UI, without depending on Nuxt
UI, Tailwind CSS, or a class-merging runtime.

## Live example

::analytics-ui-docs-example{kind="styling"}
::

The UI entry imports its base CSS automatically:

```ts
import { AnalyticsAreaChart } from '@liria24/analytics/vue/ui'
```

Use the explicit `@liria24/analytics/vue/ui/style.css` export only when a build tool requires a
separate stylesheet entry.

## Class contract

`class` styles the root. `ui` styles default markup by semantic purpose:

```vue
<AnalyticsAreaChart
    class="rounded-lg border p-4"
    :report="report"
    :ui="{ title: 'font-semibold', legend: ['text-xs', 'gap-3'], plot: 'mt-4' }"
/>
```

Public class values are deliberately framework-neutral:

```ts
type AnalyticsUIClass = string | readonly string[]
```

Vue class-object syntax is not part of the contract. Chart keys include `root`, `header`,
`title`, `plot`, `legend`, `legendItem`, `legendIndicator`, `tooltip`, `tooltipLabel`,
`tooltipItem`, `quality`, and `empty`. Table keys use semantic names such as `table`, `header`,
`body`, `row`, `headerCell`, and `cell` rather than DOM tag names.

## Slots

Slots replace markup; `ui` styles the default markup. Slot props therefore contain report data,
not the resolved `ui` object:

```vue
<AnalyticsStat :report="report" metric="pageViews">
    <template #value="{ formatted, value }">
        <strong class="custom-value" :data-value="value">{{ formatted }}</strong>
    </template>
</AnalyticsStat>
```

## Semantic CSS variables

Defaults are owned by the SDK and include dark-mode values. They do not implicitly fall back to
Nuxt UI variables.

| Variable                                      | Purpose                        |
| --------------------------------------------- | ------------------------------ |
| `--analytics-text`                            | Default text                   |
| `--analytics-text-muted`                      | Secondary text and axes        |
| `--analytics-text-highlighted`                | Titles and emphasized values   |
| `--analytics-border`                          | Borders and grid               |
| `--analytics-background`                      | Tooltip and surface background |
| `--analytics-chart-axis`                      | Axis labels                    |
| `--analytics-chart-grid`                      | Grid lines                     |
| `--analytics-chart-1` … `--analytics-chart-6` | Series colors                  |

Override variables on the component or an ancestor. A Nuxt UI color mapping can be added by the
application as an optional preset:

```css
.analytics-panel {
    --analytics-text-muted: var(--ui-text-muted);
    --analytics-border: var(--ui-border);
    --analytics-chart-grid: var(--ui-border-muted);
}
```
