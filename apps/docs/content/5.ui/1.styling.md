title: Styling
description: Customize Metric UI with semantic slots, classes, CSS variables, and formatters.
---

::insight-ui-docs-example{kind="styling"}
::

`ui` overrides semantic component slots. CSS variables customize chart colors without exposing the
private renderer. Presentation belongs in UI options:

```vue
<InsightStat
    :data="dashboard.revenue"
    metric="mrr"
    :formatter="(value) => currency.format(value)"
/>
```

Metric `unit`, aggregation, and rollup remain semantic metadata; percent, currency, compact
notation, locale, and fraction digits remain presentation.
