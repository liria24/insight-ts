---
title: AnalyticsStat
description: Render one metric from an analytics scalar report.
---

`AnalyticsStat` accepts an `AnalyticsScalarReport`. Passing a series or table report is a type
error; transform or query the correct report kind before rendering.

## Live example

::analytics-ui-docs-example{kind="stat"}
::

```vue
<AnalyticsStat :report="report" metric="pageViews" label="Page views" />
```

## UI and slots

Semantic `ui` keys are `root`, `label`, `value`, `quality`, and `empty`.

```vue
<AnalyticsStat :report="report" metric="pageViews" :ui="{ value: 'tabular-nums' }">
    <template #value="{ value, formatted }">
        <strong :data-value="value">{{ formatted }}</strong>
    </template>
</AnalyticsStat>
```

Slots are `label` (`label`, `metric`), `value` (`value`, `formatted`, `metric`), `quality`
(`messages`, `quality`), and `empty` (`metric`). Slot props do not expose the resolved `ui`
object.

## API

| Prop                    | Type                    | Default               |
| ----------------------- | ----------------------- | --------------------- |
| `report`                | `AnalyticsScalarReport` | required              |
| `metric`                | `string`                | required              |
| `label`                 | `string`                | generated metric name |
| `locale`                | `string`                | `en-US`               |
| `maximumFractionDigits` | `number`                | `2`                   |
| `emptyText`             | `string`                | `No data`             |
| `class`                 | `AnalyticsUIClass`      | —                     |
| `ui`                    | `AnalyticsStatUI`       | —                     |
