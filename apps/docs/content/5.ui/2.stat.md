---
title: InsightStat
description: Show the Metric value in a single-metric result with an optional label and quality notices.
---

Use `InsightStat` for a KPI, total, rate, or revenue value from a single-metric `QueryResult`. It
never fetches data or changes the result.

## Example

::code-preview
:::insight-stat{:data='{"data":{"pageViews":{"value":4140}},"meta":{"queriedAt":"2026-08-28T09:00:00.000Z","source":"docs.example"}}'}
:::

#code

```vue
<InsightStat
    :data="{
        data: { values: { pageViews: 4140 } },
        meta: {
            queriedAt: '2026-08-28T09:00:00.000Z',
            source: 'docs.example',
        },
    }"
/>
```

::

## Usage

Import the optional UI entry, then pass a single-metric result through `data`. The Metric name and
label are derived from that result.

```vue
<script setup lang="ts">
import { InsightStat } from 'insight-ts/vue/ui'
</script>
```

::note
`InsightStat` renders only cross-cutting `QueryQuality` notices. Source metadata such as freshness,
timezone, pagination, and History Fidelity stays available on `data.meta` for application UI.
::

## Props

| Prop                    | Type                        | Default              |
| ----------------------- | --------------------------- | -------------------- |
| `data`                  | Metric `QueryResult`        | required             |
| `label`                 | `string`                    | formatted metric key |
| `formatter`             | `(value: number) => string` | locale number        |
| `locale`                | `string`                    | `en-US`              |
| `maximumFractionDigits` | `number`                    | `2`                  |
| `emptyText`             | `string`                    | `No data`            |
| `class`                 | class value                 | root only            |
| `ui`                    | `InsightStatUI`             | —                    |

## Customization

`class` is appended to the root. Use `ui` for an internal semantic slot; each key accepts a class
string or readonly class array.

```vue
<InsightStat
    class="rounded-xl border border-default p-5"
    :data="dashboard.summary"
    :ui="{ label: 'text-xs uppercase tracking-wide', value: 'text-3xl font-semibold' }"
/>
```

| `ui` key  | `data-slot` | Element         |
| --------- | ----------- | --------------- |
| `root`    | `root`      | `<section>`     |
| `label`   | `label`     | metric label    |
| `value`   | `value`     | formatted value |
| `notices` | `notices`   | quality message |
| `empty`   | `empty`     | empty state     |

The component inherits these CSS variables: `--insight-text`, `--insight-text-muted`, and
`--insight-text-highlighted`.

Use `formatter` for currency, percentage, compact notation, or a domain-specific format. Use
`locale` and `maximumFractionDigits` only for the built-in number formatter.

## Slots

| Slot      | Receives                         | Replaces        |
| --------- | -------------------------------- | --------------- |
| `label`   | `{ label, metric }`              | label markup    |
| `value`   | `{ formatted, metric, value }`   | value markup    |
| `notices` | `{ messages, notices, quality }` | quality message |
| `empty`   | `{ metric }`                     | empty state     |
