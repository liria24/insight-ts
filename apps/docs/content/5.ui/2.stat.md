---
title: AnalyticsStat
description: Render one metric from a scalar or series analytics report.
---

`AnalyticsStat` displays one metric. For a series report it selects the latest point containing
that metric; for a scalar report it reads the metric directly.

## Usage

```vue
<AnalyticsStat :report="report" metric="pageViews" />
```

Use `label` to replace the generated metric name:

```vue
<AnalyticsStat label="Page views" :report="report" metric="pageViews" />
```

## Styling

```vue
<AnalyticsStat
    class="rounded-lg border p-6"
    :report="report"
    metric="pageViews"
    :ui="{
        label: 'text-xs text-muted',
        value: 'text-3xl font-semibold tabular-nums',
        caption: 'text-xs text-muted',
    }"
/>
```

### UI slots

| Key       | Target                         |
| --------- | ------------------------------ |
| `root`    | Component root                 |
| `label`   | Metric label                   |
| `value`   | Formatted metric value         |
| `caption` | Latest-point timestamp/caption |
| `quality` | Report quality message         |
| `empty`   | Empty or unavailable state     |

Each target also has a matching `data-slot` value.

## Slots

```vue
<AnalyticsStat :report="report" metric="pageViews">
    <template #value="{ value, formatted, ui }">
        <strong :class="ui.value" :data-value="value">
            {{ formatted }}
        </strong>
    </template>
</AnalyticsStat>
```

| Slot      | Props                                         | Default behavior                        |
| --------- | --------------------------------------------- | --------------------------------------- |
| `label`   | `label`, `metric`, `ui`                       | Renders the generated or explicit label |
| `value`   | `value`, `formatted`, `metric`, `point`, `ui` | Renders the localized number            |
| `caption` | `point`, `ui`                                 | Renders the latest point date           |
| `quality` | `messages`, `quality`, `ui`                   | Renders report quality warnings         |
| `empty`   | `metric`, `ui`                                | Renders the accessible empty state      |

## API

| Prop                    | Type                | Default     |
| ----------------------- | ------------------- | ----------- |
| `report`                | `AnalyticsReport`   | required    |
| `metric`                | `string`            | required    |
| `label`                 | `string`            | metric name |
| `locale`                | `string`            | `en-US`     |
| `timezone`              | `string \| 'local'` | report/UTC  |
| `maximumFractionDigits` | `number`            | `2`         |
| `emptyText`             | `string`            | `No data`   |
| `class`                 | `AnalyticsUIClass`  | —           |
| `ui`                    | `AnalyticsStatUI`   | —           |
