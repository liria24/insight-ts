---
title: InsightStat
description: Render one metric from an analytics scalar report.
---

`InsightStat` accepts a `ScalarReport`. Passing a series or table report is a type
error; transform or query the correct report kind before rendering.

## Live example

::insight-ui-docs-example{kind="stat"}
::

```vue
<InsightStat :report="report" metric="pageViews" label="Page views" />
```

## UI and slots

Semantic `ui` keys are `root`, `label`, `value`, `notices`, and `empty`.

```vue
<InsightStat :report="report" metric="pageViews" :ui="{ value: 'tabular-nums' }">
    <template #value="{ value, formatted }">
        <strong :data-value="value">{{ formatted }}</strong>
    </template>
</InsightStat>
```

Slots are `label` (`label`, `metric`), `value` (`value`, `formatted`, `metric`), `notices`
(`messages`, `notices`), and `empty` (`metric`). Slot props do not expose the resolved `ui`
object.

## API

| Prop                    | Type             | Default               |
| ----------------------- | ---------------- | --------------------- |
| `report`                | `ScalarReport`   | required              |
| `metric`                | `string`         | required              |
| `label`                 | `string`         | generated metric name |
| `locale`                | `string`         | `en-US`               |
| `maximumFractionDigits` | `number`         | `2`                   |
| `emptyText`             | `string`         | `No data`             |
| `class`                 | `InsightUIClass` | —                     |
| `ui`                    | `InsightStatUI`  | —                     |
