---
title: InsightStat
description: Render one selected Metric value.
---

::insight-ui-docs-example{kind="stat"}
::

```vue
<InsightStat :data="dashboard.trafficSummary" metric="pageViews" />
```

`metric` is inferred from `data` where possible. Use `formatter` for currency, percent, or compact
notation. The component renders `QueryQuality` notices but never Source-specific temporal,
pagination, or History metadata.

| Prop        | Type                        | Default              |
| ----------- | --------------------------- | -------------------- |
| `data`      | Metric `QueryResult`        | required             |
| `metric`    | selected Metric key         | required             |
| `formatter` | `(value: number) => string` | locale number        |
| `label`     | `string`                    | formatted Metric key |
