---
title: InsightAreaChart
description: Render all selected Metric series as unstacked areas.
---

::insight-ui-docs-example{kind="area"}
::

```vue
<InsightAreaChart :data="dashboard.trafficSeries" smooth title="Traffic" />
```

Every selected metric is rendered in Source order. Areas overlay rather than stack. Metric
selection belongs in the Source query, so no UI `metrics` prop exists.
