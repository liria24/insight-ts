---
title: InsightAreaChart
description: Render unstacked, overlaid analytics series as an SSR area chart.
---

`InsightAreaChart` shares the high-level series API with `InsightLineChart`. It renders an
area and its upper line for each metric; multiple metrics overlay and are never implicitly
stacked.

## Live example

::insight-ui-docs-example{kind="area"}
::

```vue
<script setup lang="ts">
import type { SeriesReport } from 'insight-ts'
import { InsightAreaChart } from 'insight-ts/vue/ui'

defineProps<{ report: SeriesReport }>()
</script>

<template>
    <InsightAreaChart smooth :report="report" :metrics="['pageViews', 'visits']" title="Traffic" />
</template>
```

Analytics metrics such as page views, visits, users, and sessions are not necessarily additive,
so there is no `stacked` prop. `smooth="false"` uses linear segments; `smooth` uses a monotone
curve.

## SSR and accessibility

TanStack Charts server-renders the complete SVG. The response also contains title, legend,
notices/empty state, a fixed-height plot, and a visually hidden exact-value table. The SVG uses a
deterministic initial width so hydration does not replace it or shift the chart region.

TanStack Charts remains an internal implementation detail. Use the same semantic `ui` keys and
`title`, `legend`, `tooltip`, `notices`, and `empty` slots documented for
[InsightLineChart](/ui/line-chart#ui-and-slots).

## API

The props match `InsightLineChart`, except `ui` is typed as `InsightAreaChartUI`. `report` is
strictly `SeriesReport`; no renderer variant or renderer configuration is exposed.
