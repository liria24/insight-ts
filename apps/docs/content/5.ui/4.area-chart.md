---
title: InsightAreaChart
description: Plot every selected Metric series as unstacked areas.
---

Use `InsightAreaChart` when the change and relative volume of each selected Metric matters. Areas
overlay one another; they are never stacked or combined.

## Example

<InsightAreaChart
    :data="{
        data: {
            points: [

                { time: '2026-08-27T00:00:00.000Z', values: { pageViews: 1510 } },
                { time: '2026-08-28T00:00:00.000Z', values: { pageViews: 1390 } },

## Usage

```vue
<script setup lang="ts">
import { InsightAreaChart } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightAreaChart :data="dashboard.trafficSeries" title="Traffic" />
</template>
```

The selected metrics are rendered in Source order. Keep selection in the query; this component has
no `metrics` prop and performs no aggregation.

## Props

| Prop       | Type                                   | Default                        |
| ---------- | -------------------------------------- | ------------------------------ |
| `data`     | Metric `QueryResult` with time points  | required                       |
| `title`    | `string`                               | —                              |
| `height`   | `number`                               | `360`                          |
| `colors`   | `readonly string[]`                    | six `--insight-chart-*` colors |
| `smooth`   | `boolean`                              | `false`                        |
| `locale`   | `string`                               | `en-US`                        |
| `timezone` | `local`, `source`, `utc`, or IANA zone | local                          |
| `xAxis`    | `XAxisOptions`                         | —                              |
| `yAxis`    | `YAxisOptions`                         | —                              |
| `class`    | class value                            | root only                      |
| `ui`       | `InsightAreaChartUI`                   | —                              |

## Customization

```vue
<InsightAreaChart
    class="traffic-area"
    :colors="['#0ea5e9', '#8b5cf6']"
    :data="dashboard.trafficSeries"
    :ui="{ header: 'mb-4', title: 'text-lg font-semibold' }"
    :y-axis="{ domain: { min: 0 }, formatter: (value) => `${value}%` }"
/>
```

| `ui` key          | `data-slot`        | Element                  |
| ----------------- | ------------------ | ------------------------ |
| `root`            | `root`             | chart section            |
| `header`          | `header`           | title and legend wrapper |
| `title`           | `title`            | heading                  |
| `plot`            | `plot`             | chart and fidelity bands |
| `legend`          | `legend`           | series list              |
| `legendItem`      | `legend-item`      | series item              |
| `legendIndicator` | `legend-indicator` | color marker             |
| `tooltip`         | `tooltip`          | tooltip panel            |
| `tooltipLabel`    | `tooltip-label`    | tooltip time label       |
| `tooltipItem`     | `tooltip-item`     | tooltip series value     |
| `notices`         | `notices`          | quality message          |
| `empty`           | `empty`            | empty state              |

The component inherits `--insight-text`, `--insight-text-muted`, `--insight-text-highlighted`,
`--insight-border`, `--insight-background`, `--insight-chart-axis`, `--insight-chart-grid`, and
`--insight-chart-1` through `--insight-chart-6`.

Use `xAxis.formatter` for dates and `yAxis.formatter` for values. `colors` changes series colors;
no renderer-specific configuration is part of the public API.

## Slots

| Slot      | Receives                         | Replaces        |
| --------- | -------------------------------- | --------------- |
| `title`   | `{ title }`                      | title markup    |
| `legend`  | `{ series }`                     | legend markup   |
| `tooltip` | `{ label, point, values }`       | tooltip markup  |
| `notices` | `{ messages, notices, quality }` | quality message |
| `empty`   | `{ message }`                    | empty state     |
