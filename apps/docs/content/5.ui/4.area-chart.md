---
title: AnalyticsAreaChart
description: Render unstacked, overlaid analytics series as an SSR area chart.
---

`AnalyticsAreaChart` shares the high-level series API with `AnalyticsLineChart`. It renders an
area and its upper line for each metric; multiple metrics overlay and are never implicitly
stacked.

## Live example

::analytics-ui-docs-example{kind="area"}
::

```vue
<script setup lang="ts">
import type { AnalyticsSeriesReport } from '@liria24/analytics'
import { AnalyticsAreaChart } from '@liria24/analytics/vue/ui'

defineProps<{ report: AnalyticsSeriesReport }>()
</script>

<template>
    <AnalyticsAreaChart
        smooth
        :report="report"
        :metrics="['pageViews', 'visits']"
        title="Traffic"
    />
</template>
```

Analytics metrics such as page views, visits, users, and sessions are not necessarily additive,
so there is no `stacked` prop. `smooth="false"` uses linear segments; `smooth` uses a monotone
curve.

## SSR and accessibility

TanStack Charts server-renders the complete SVG. The response also contains title, legend,
quality/empty state, a fixed-height plot, and a visually hidden exact-value table. The SVG uses a
deterministic initial width so hydration does not replace it or shift the chart region.

TanStack Charts remains an internal implementation detail. Use the same semantic `ui` keys and
`title`, `legend`, `tooltip`, `quality`, and `empty` slots documented for
[AnalyticsLineChart](/ui/line-chart#ui-and-slots).

## API

The props match `AnalyticsLineChart`, except `ui` is typed as `AnalyticsAreaChartUI`. `report` is
strictly `AnalyticsSeriesReport`; no renderer variant or renderer configuration is exposed.
