---
title: AnalyticsBreakdownTable
description: Render analytics table reports without aggregating or changing provider rows.
---

`AnalyticsBreakdownTable` renders dimensions and metrics from a table report. It preserves each
row exactly as reported and does not aggregate breakdown values.

## Usage

```vue
<AnalyticsBreakdownTable
    :dimensions="['country']"
    :metrics="['pageViews', 'visits']"
    :report="report"
/>
```

When `dimensions` or `metrics` is omitted, available fields are selected from the report in their
encountered order. Unknown requested fields are ignored.

## Styling

```vue
<AnalyticsBreakdownTable
    class="overflow-hidden rounded-lg border"
    :report="report"
    :ui="{
        th: 'bg-muted px-4 py-2 text-xs font-medium',
        td: 'border-t px-4 py-3 text-sm',
    }"
/>
```

### UI slots

| Key       | Target                             |
| --------- | ---------------------------------- |
| `root`    | Component root                     |
| `base`    | `<table>`                          |
| `thead`   | `<thead>`                          |
| `tbody`   | `<tbody>`                          |
| `tr`      | Header and body rows               |
| `th`      | Header cells                       |
| `td`      | Body cells                         |
| `quality` | Report quality message             |
| `empty`   | Empty or incompatible report state |

## Slots

```vue
<AnalyticsBreakdownTable :report="report">
    <template #cell="{ kind, formatted, ui }">
        <span :class="ui.td" :data-kind="kind">
            {{ formatted }}
        </span>
    </template>
</AnalyticsBreakdownTable>
```

| Slot      | Props                                                    | Default behavior                  |
| --------- | -------------------------------------------------------- | --------------------------------- |
| `table`   | `dimensions`, `metrics`, `rows`, `ui`                    | Renders the semantic table        |
| `header`  | `column`, `ui`                                           | Renders a formatted column name   |
| `cell`    | `column`, `formatted`, `kind`, `rowIndex`, `value`, `ui` | Renders a formatted cell          |
| `quality` | `messages`, `quality`, `ui`                              | Renders report quality warnings   |
| `empty`   | `reason`, `ui`                                           | Renders an accessible empty state |

## API

| Prop                    | Type                        | Default    |
| ----------------------- | --------------------------- | ---------- |
| `report`                | `AnalyticsReport`           | required   |
| `dimensions`            | `readonly string[]`         | all fields |
| `metrics`               | `readonly string[]`         | all fields |
| `locale`                | `string`                    | `en-US`    |
| `maximumFractionDigits` | `number`                    | `2`        |
| `emptyText`             | `string`                    | `No data`  |
| `class`                 | `AnalyticsUIClass`          | —          |
| `ui`                    | `AnalyticsBreakdownTableUI` | —          |
