---
title: InsightBreakdownTable
description: Display every selected Metric dimension and value in a table.
---

Use `InsightBreakdownTable` for an already queried dimension breakdown, such as traffic by country
or revenue by plan. It displays the dimensions and metrics returned by the Source without changing
their selection.

## Example

::code-preview
:::insight-breakdown-table{:data='{"data":{"pageViews":{"points":[{"dimensions":{"country":"Japan"},"value":1240},{"dimensions":{"country":"United States"},"value":1510},{"dimensions":{"country":"Germany"},"value":1390}],"value":4140}},"meta":{"queriedAt":"2026-08-28T09:00:00.000Z","source":"docs.example"}}'}
:::

#code

```vue
<InsightBreakdownTable
    :data="{
        data: {
            points: [
                { dimensions: { country: 'Japan' }, values: { pageViews: 1240 } },
                { dimensions: { country: 'United States' }, values: { pageViews: 1510 } },
                { dimensions: { country: 'Germany' }, values: { pageViews: 1390 } },
            ],
            values: { pageViews: 4140 },
        },
        meta: {
            queriedAt: '2026-08-28T09:00:00.000Z',
            source: 'docs.example',
        },
    }"
/>
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightBreakdownTable } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightBreakdownTable :data="dashboard.countries" />
</template>
```

The table does not aggregate, reorder, or introduce duplicate `dimensions` or `metrics` props.
Select exactly what the view needs in the Source query.

## Props

| Prop                    | Type                                       | Default   |
| ----------------------- | ------------------------------------------ | --------- |
| `data`                  | Metric `QueryResult` with dimension points | required  |
| `emptyText`             | `string`                                   | `No data` |
| `locale`                | `string`                                   | `en-US`   |
| `maximumFractionDigits` | `number`                                   | `2`       |
| `class`                 | class value                                | root only |
| `ui`                    | `InsightBreakdownTableUI`                  | —         |

## Customization

```vue
<InsightBreakdownTable
    class="overflow-x-auto rounded-xl border border-default"
    :data="dashboard.countries"
    :ui="{ headerCell: 'bg-muted/40 font-semibold', cell: 'whitespace-nowrap' }"
/>
```

| `ui` key     | `data-slot`   | Element              |
| ------------ | ------------- | -------------------- |
| `root`       | `root`        | table section        |
| `table`      | `table`       | `<table>`            |
| `header`     | `header`      | `<thead>`            |
| `body`       | `body`        | `<tbody>`            |
| `row`        | `row`         | header and body rows |
| `headerCell` | `header-cell` | column heading       |
| `cell`       | `cell`        | body cell            |
| `notices`    | `notices`     | quality message      |
| `empty`      | `empty`       | empty state          |

The component inherits `--insight-text`, `--insight-text-muted`, and `--insight-border`. Numeric
cells use the built-in number formatter controlled by `locale` and `maximumFractionDigits`; use the
`cell` slot for a per-value formatter.

## Slots

| Slot      | Receives                                       | Replaces           |
| --------- | ---------------------------------------------- | ------------------ |
| `header`  | `{ column }`                                   | a column heading   |
| `cell`    | `{ column, formatted, kind, rowIndex, value }` | a table cell value |
| `notices` | `{ messages, notices, quality }`               | quality message    |
| `empty`   | `{ message }`                                  | empty state        |
