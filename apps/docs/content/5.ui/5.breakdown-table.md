---
title: InsightBreakdownTable
description: Render all selected Metric dimensions and values.
---

::insight-ui-docs-example{kind="breakdown"}
::

```vue
<InsightBreakdownTable :data="dashboard.countries" />
```

The table displays every selected dimension and metric already present in `data`. It does not
aggregate, reorder, or expose duplicate `dimensions`/`metrics` selection props.
