---
title: InsightBreakdownTable
description: Render analytics table reports without aggregating provider rows.
---

`InsightBreakdownTable` strictly accepts a `TableReport`. It formats each row without
aggregating or changing provider values.

## Live example

::insight-ui-docs-example{kind="breakdown"}
::

```vue
<InsightBreakdownTable
    :report="report"
    :dimensions="['country']"
    :metrics="['pageViews', 'visits']"
    :ui="{ headerCell: 'font-medium', cell: 'tabular-nums' }"
/>
```

Omitted field lists use the report's encountered order. Unknown fields are ignored.

Semantic UI keys are `root`, `table`, `header`, `body`, `row`, `headerCell`, `cell`, `notices`,
and `empty`. DOM names such as `thead`, `tr`, and `td` are not public styling contracts.

```vue
<InsightBreakdownTable :report="report">
    <template #cell="{ kind, formatted }">
        <span :data-kind="kind">{{ formatted }}</span>
    </template>
</InsightBreakdownTable>
```

Slots are `header` (`column`), `cell` (`column`, `formatted`, `kind`, `rowIndex`, `value`),
`notices` (`messages`, `notices`), and `empty` (`message`). Slot props do not expose `ui`.

## API

| Prop                    | Type                      | Default    |
| ----------------------- | ------------------------- | ---------- |
| `report`                | `TableReport`             | required   |
| `dimensions`            | `readonly string[]`       | all fields |
| `metrics`               | `readonly string[]`       | all fields |
| `locale`                | `string`                  | `en-US`    |
| `maximumFractionDigits` | `number`                  | `2`        |
| `emptyText`             | `string`                  | `No data`  |
| `class`                 | `InsightUIClass`          | —          |
| `ui`                    | `InsightBreakdownTableUI` | —          |
