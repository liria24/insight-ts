title: Concepts
description: The mental model for Providers, Sources, Metric helpers, quality, and optional features.
---

The main execution path is simple: **Provider → Source → `insight.query()` → `QueryResult`**.

- A **Provider** groups one or more Sources and can optionally deliver application events.
- A **Source** owns its query shape, normalization, exact dedupe key, execution, data, and metadata.
- **Core** selects Sources lazily, groups work by Provider, bounds execution, and creates the common
  result envelope.
- **QueryQuality** carries only cross-cutting approximation, partiality, sampling, thresholding, and
  warnings.

## Results keep Source meaning

Every result has `data` plus `meta.source`, `meta.queriedAt`, optional `meta.quality`, and
Source-defined metadata.

```ts
const result = await insight.query((q) => ({
    traffic: q.source('cloudflare.webAnalytics', trafficQuery),
}))

result.traffic.meta.source
result.traffic.meta.quality
```

A log cursor, billing entity, Metric time grain, Provider freshness, and History Fidelity remain
Source-specific. Core does not turn them into a generic analytics schema.

## Metrics are optional helpers

`insight-ts/metrics` adds Metric definitions, dimensions, typed object filters, structured
aggregation, and safe History rollup over the generic Source contract.

```ts
where: {
    country: 'JP',
    device: { in: ['mobile', 'tablet'] },
    NOT: { path: { contains: '/admin' } },
}
```

Fields in one object are ANDed. Use `AND`, `OR`, and `NOT` for explicit groups; TypeScript exposes
only operators that the Source supports.

## Optional features

History materializes Source-declared Metric ranges. Browser events use a bounded same-origin relay.
`insight-ts/ui-core` creates framework-neutral Metric models, and `insight-ts/vue/ui` renders those
results without doing Provider I/O.

::collapsible{name="Why no universal report type?"}
Different Providers have incompatible query languages, retention rules, quality signals, and result
shapes. Source-owned contracts preserve those facts while Core still gives applications one typed
execution API.
::
