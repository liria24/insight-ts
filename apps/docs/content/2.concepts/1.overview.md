The execution path is **Provider → Source → `insight.query()` → QueryResult**.

- A Provider groups Sources and optional event delivery.
- A Source owns `normalize()`, `key()`, `execute()`, query types, data, and metadata.
- Core executes heterogeneous selections without interpreting their semantics.
- `QueryQuality` shares only approximation, partiality, sampling, thresholding, and warnings.

`defineMetricSource()` adds selected metrics, dimensions, structured aggregation, typed filters,
and optional Metric History over the generic Source contract.

```ts
where: {
    country: 'JP',
    device: { in: ['mobile', 'tablet'] },
    NOT: { path: { contains: '/admin' } },
}
```

Fields and operators in one object are implicit AND. `AND`, `OR`, and `NOT` form explicit groups.
Each field exposes only valid operator/value pairs.

OTel supplies observability semantics and trace interoperability. Public UI is Metric-only;
Source-owned funnel, log, trace, and billing data uses dedicated application UI.
