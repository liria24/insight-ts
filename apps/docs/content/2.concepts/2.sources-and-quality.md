---
title: Sources and quality
description: How the SDK selects providers and preserves report reliability metadata.
---

Analytics SDK resolves one source for each query in this order:

1. the query's explicit `source`;
2. an explicit default for the requested domain;
3. the only compatible configured source.

If multiple compatible sources remain, the query fails with an actionable error. The SDK does not
select the first adapter and does not merge provider totals automatically.

```ts
const analytics = createAnalytics({
    name: 'website',
    adapters: [webAnalytics, searchConsole],
    defaultSources: {
        traffic: 'cloudflare-web-analytics',
        search: 'google-search-console',
    },
})
```

## Quality is part of the report

Provider limitations remain visible in `report.meta`:

```ts
const { freshness, quality, source, temporal } = report.meta
```

`quality` can describe sampling, approximation, thresholds, partial results, imported archive
data, and warnings. `freshness` can identify complete and incomplete coverage. `temporal`
records the source timezone and report bucket timezone when they matter.

Applications should surface this information when it changes how a report should be interpreted.
Do not discard it when caching, rendering, or exporting a report.
