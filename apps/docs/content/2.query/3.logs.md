---
title: Logs
description: Query a stable, typed Log model across observability Providers.
---

After configuring a Provider with canonical Logs, query them through `insight.logs()`. Results use
stable Log IDs and newest-first timestamps. Structured bodies and Provider-mapped attributes are
preserved.

```ts
const errors = await insight.logs({
    limit: 50,
    time: { from, to },
    where: {
        severity: { in: ['error', 'fatal'] },
        service: 'api',
        attributes: { tenant: 'acme' },
    },
})
```

Portable fields are `severity`, `service`, `environment`, `traceId`, and `spanId`. The typed
`attributes` record is the escape hatch for Provider-specific fields. Configured Provider support
determines which filters are available; incompatible filters fail before Provider I/O.

Every record has a stable `id` and `timestamp`. Optional mapped fields include observed time,
severity text, service, environment, trace/span IDs, attributes, and an unmodified structured
`body`. Provider Quality is conservatively summarized in `meta.quality`.
