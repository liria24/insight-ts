---
title: Filtering and time
description: Express supported filters and absolute half-open time ranges.
---

Canonical queries use absolute half-open ranges: `from` is included and `to` is excluded. Metrics
may add a `grain`; Logs and Traces retain event timestamps and newest-first ordering.

```ts
q.logs({
    time: { from: '2026-08-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
    where: [{ field: 'severity', operator: 'in', value: ['error', 'fatal'] }],
})
```

Core validates the shared filter and time shape. Each adapter validates native fields, operators,
grains, ranges, and limits before network I/O. Unsupported filters fail instead of being silently
discarded.
