---
title: Metrics
description: Query canonical values, time series, and dimensional breakdowns.
---

Metrics describe named numeric measurements independently of a Provider's native API. Select the
values you need and add dimensions only when the result must be broken down.

```ts
const traffic = await insight.metrics({
    dimensions: ['country'],
    metrics: ['pageViews', 'visits'],
    projection: 'both',
    time: { from, to, grain: 'day' },
})
```

Choose the result shape with `projection`:

- `aggregate` returns only the query-wide values.
- `rows` returns only the grouped rows, including an empty array when no rows match.
- `both` returns both fields.

An ungrouped query without a time grain defaults to `aggregate`. Adding dimensions or a grain changes
the default to `both`. An explicit projection also narrows the inferred TypeScript result type.

`limit` applies only to grouped rows. The query-wide aggregate is a separate Provider projection and
is never calculated from limited rows. Each row keeps Metric values under `row.values`. Metric
definitions retain units, aggregation, and safe rollup semantics. History executes the whole query
live when it cannot reconstruct every selected projection safely.
