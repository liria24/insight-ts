---
title: Scopes
description: Select one logical environment without exposing Provider routing.
---

A Scope is a logical query and Track boundary such as `production` or `staging`. Configure either
one `providers` list or multiple named `scopes`, never both.

```ts
const insight = createInsight({
    scopes: { production: productionProviders, staging: stagingProviders },
})

const production = insight.scope('production')
const traffic = await production.metrics({ metrics: ['visits'], time })
```

Applications choose the Scope and canonical capability. Provider routing remains internal and is
not accepted by public Query or History APIs.
