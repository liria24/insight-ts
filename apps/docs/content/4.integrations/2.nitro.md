---
title: Nitro
description: Connect Metric History to Nitro Storage and optional sync tasks.
---

`insight-ts/nitro` adapts the three-method History Repository to the `insight` storage mount. It
does not depend on H3, so H3, Hono, Elysia, and Web-standard entries can share it.

```ts
const repository = createNitroHistoryRepository(useStorage('insight'))
```

```ts
export default defineNitroConfig({
    storage: { insight: { driver: 'cloudflare-r2-binding', binding: 'INSIGHT_HISTORY' } },
    devStorage: { insight: { driver: 'fs', base: '.data/insight' } },
})
```

History never falls back to process memory or another implicit store. The optional
`insight:history:sync` task only wakes `sync()`; planning, coverage, safe rollup, reduction,
Fidelity, and identity stay in the Engine.
