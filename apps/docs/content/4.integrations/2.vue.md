`@liria24/analytics/vue` is a report-only UI library for analytics. It turns existing scalar,
series, and table reports into accessible Vue components without owning data access.

## Installation

```bash
bun add @liria24/analytics vue vue-data-ui
```

Plain Vue applications import the component styles once:

```ts [main.ts]
import '@liria24/analytics/vue/style.css'
```

Nuxt applications normally do not need that import. The Analytics Nuxt module detects Vue UI
component usage and injects the stylesheet automatically.

## Philosophy

Analytics Vue UI is:

- report-only;
- provider-independent;
- not responsible for queries or caching;
- never responsible for credentials;
- a set of presentation primitives, not a full dashboard.

This keeps the same component usable with a live provider report, an archive report, a merged
report, or deterministic local data.

## Nuxt and Vue responsibilities

| Entry                              | Responsibility                                                   |
| ---------------------------------- | ---------------------------------------------------------------- |
| `@liria24/analytics/nuxt`          | Runtime integration, server configuration, routes, and storage   |
| `@liria24/analytics/vue`           | Report presentation, formatting, styles, and browser composition |
| `@liria24/analytics/vue/style.css` | Baseline component CSS and semantic chart variables              |

The Nuxt module does not auto-register Vue components. Import each primitive where it is used.

## Usage

```vue
<script setup lang="ts">
import type { AnalyticsSeriesReport } from '@liria24/analytics'
import { AnalyticsLineChart, AnalyticsStat } from '@liria24/analytics/vue'

defineProps<{ report: AnalyticsSeriesReport }>()
</script>

<template>
    <AnalyticsStat :report="report" metric="pageViews" />
    <AnalyticsLineChart :report="report" :metrics="['pageViews', 'visits']" />
</template>
```

Continue with:

- [Styling](/ui/styling) for `class`, `ui`, `data-slot`, and CSS variables;
- [AnalyticsStat](/ui/stat) for one current metric;
- [AnalyticsLineChart](/ui/line-chart) for time series;
- [AnalyticsBreakdownTable](/ui/breakdown-table) for dimensional rows.

## Browser client injection

The Vue entry also exports `provideAnalytics()` and `useAnalytics()` for a browser client created
with `@liria24/analytics/browser`. These composables are independent from report components and do
not require the Vue UI stylesheet.
