---
title: Vue
description: Add provider-independent analytics presentation primitives to Vue or Nuxt.
---

`@liria24/analytics/vue` contains only browser-client injection. UI components live in the
separate `@liria24/analytics/vue/ui` entry and receive already-created reports.

## Installation

```bash
bun add @liria24/analytics vue
```

Importing `@liria24/analytics/vue/ui` automatically includes its base stylesheet. The
`@liria24/analytics/vue/ui/style.css` export remains available as an escape hatch, but normal
usage needs no explicit CSS import.

## Entry points

| Entry                             | Responsibility                                           |
| --------------------------------- | -------------------------------------------------------- |
| `@liria24/analytics/vue`          | `provideAnalytics()` and `useAnalytics()`                |
| `@liria24/analytics/presentation` | Framework-independent report formatting and chart models |
| `@liria24/analytics/vue/ui`       | `AnalyticsStat`, Line/Area charts, and breakdown table   |

```vue
<script setup lang="ts">
import type { AnalyticsScalarReport, AnalyticsSeriesReport } from '@liria24/analytics'
import { AnalyticsAreaChart, AnalyticsStat } from '@liria24/analytics/vue/ui'

defineProps<{ summary: AnalyticsScalarReport; traffic: AnalyticsSeriesReport }>()
</script>

<template>
    <AnalyticsStat :report="summary" metric="pageViews" />
    <AnalyticsAreaChart :report="traffic" :metrics="['pageViews', 'visits']" />
</template>
```

Each component requires the matching report kind at compile time. A scalar report is accepted by
`AnalyticsStat`, a series report by Line/Area charts, and a table report by
`AnalyticsBreakdownTable`.

## Renderer and SSR

TanStack Charts is the internal chart renderer and is versioned by the SDK. Its marks, scales,
types, and configuration are not public Analytics contracts.

Line and Area charts server-render their SVG, title, legend, quality state, and exact-value
semantic table. The same SVG hydrates on the client with a deterministic initial width. Apps
using only `@liria24/analytics/vue`, the core package, or the Nuxt module do not import the UI,
chart renderer, or UI CSS.

The UI is report-only: it does not query providers, cache results, own credentials, or choose a
dashboard layout.
