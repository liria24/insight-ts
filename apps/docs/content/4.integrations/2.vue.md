---
title: Vue
description: Render analytics reports with optional report-only Vue primitives.
---

The Vue entry provides small presentation primitives for reports you already have. Components do
not query providers, call endpoints, cache data, access archives, or handle credentials.

Install Vue and the chart dependency:

```bash
bun add vue vue-data-ui
```

Import the component and Vue Data UI styles explicitly:

```vue
<script setup lang="ts">
import 'vue-data-ui/style.css'
import type { AnalyticsSeriesReport } from '@liria24/analytics'
import { AnalyticsLineChart, AnalyticsStat } from '@liria24/analytics/vue'

defineProps<{ report: AnalyticsSeriesReport }>()
</script>

<template>
    <AnalyticsStat :report="report" metric="pageViews" />
    <AnalyticsLineChart :report="report" :metrics="['pageViews', 'visits']" />
</template>
```

Available components:

- `AnalyticsStat` renders one metric with optional caption and quality state.
- `AnalyticsLineChart` transforms a series report for Vue Data UI.
- `AnalyticsBreakdownTable` renders a table report or dimensional breakdown.

The Nuxt module does not register these components. Import only the primitives your application
uses.

## Browser client injection

The Vue entry also exports `provideAnalytics()` and `useAnalytics()` for a browser client created
with `@liria24/analytics/browser`. This is independent from the report components.
