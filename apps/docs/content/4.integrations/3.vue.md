---
title: Vue
description: Use optional browser integration and Metric UI without coupling them.
---

`insight-ts/vue` only provides the browser event client. Metric UI is a separate entry:

```vue
<script setup lang="ts">
import { InsightAreaChart, InsightStat } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightStat :data="dashboard.analytics.trafficSummary" metric="pageViews" />
    <InsightAreaChart :data="dashboard.analytics.trafficSeries" />
</template>
```

Every data-bearing prop is `data`. Line and area charts draw all metrics selected by the Source in
insertion order. Stat, Sparkline, and BarChart retain only presentation selections. Funnel, logs,
traces, and billing remain application-local renderers.
