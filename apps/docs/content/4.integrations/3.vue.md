---
title: Vue
description: Use the optional Vue browser integration and report UI without coupling them.
---

`insight-ts/vue` contains only browser integration:

```ts
import { createBrowserInsight } from 'insight-ts/browser'
import { provideBrowserInsight, useBrowserInsight } from 'insight-ts/vue'

provideBrowserInsight(createBrowserInsight())
const browser = useBrowserInsight()
```

It does not import CSS, TanStack Charts, or report components.

## Optional report UI

```vue
<script setup lang="ts">
import type { ScalarReport, SeriesReport } from 'insight-ts'
import { InsightAreaChart, InsightStat } from 'insight-ts/vue/ui'

defineProps<{ summary: ScalarReport; traffic: SeriesReport }>()
</script>

<template>
    <InsightStat :report="summary" metric="pageViews" />
    <InsightAreaChart :report="traffic" :metrics="['pageViews', 'visits']" />
</template>
```

The UI entry automatically loads its base stylesheet. TanStack Charts is private to the Vue
Line/Area implementation; renderer configuration and types are not public contracts.

Components server-render a complete SVG, fixed plot height, title, legend, notices, and an
exact-value semantic table. The same SFC source compiles with Vue 3.5 VDOM and is ready for Vue
3.6 Vapor compilation. Insight.ts does not publish a separate Vapor entry and the Nuxt module
does not toggle Vapor for an application.

Framework-neutral formatting, selection, tooltip, Quality, and Fidelity models live in
`insight-ts/ui-core`. Other UI integrations can reuse those models without adopting Vue or
TanStack Charts.
