title: Releases
description: Versioning and release history.
---

Liria Analytics starts at `0.0.1`. While the package remains on `0.x`, releases can include
breaking changes.

GitHub Releases are the canonical release history. Stable releases use `vX.Y.Z` tags and are
published to npm as `@liria24/analytics`.

See [GitHub Releases](https://github.com/liria24/analytics/releases).
