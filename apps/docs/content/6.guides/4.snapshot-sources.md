---
title: Snapshot sources
description: Model current-only application values as normal Report Sources.
---

There is no special application-state API. Define a Report Source with `snapshot()` and snapshot
History:

```ts
const app = defineProvider({
    id: 'app',
    reports: {
        usage: {
            metrics: {
                seats: { valueType: 'integer', aggregation: 'last', rollup: 'non-additive' },
            },
            history: { mode: 'snapshot' },
            async snapshot() {
                return { values: { seats: await countSeats() } }
            },
        },
    },
})
```

`insight.history.capture()` stores observations. A later `series()` query is synthesized from those
observations using the same Core report model.
