---
title: Data model
description: Understand generic Source results, Metric data, and metadata boundaries.
---

Core constructs one envelope:

```ts
interface QueryResult<TData, TMeta extends object = {}> {
    data: TData
    meta: TMeta & { source: string; queriedAt: string; quality?: QueryQuality }
}
```

`TData` and `TMeta` belong to the Source. A log cursor, trace graph, funnel steps, billing entities,
Metric time grain, and freshness do not become Core concepts.

Metric Sources represent each selected metric as `{ value: number | null, points? }`. Definitions
carry semantic `label`, `unit`, structured `aggregation`, and `rollup`. UI presentation carries
currency, percent, compact notation, locale, and fraction digits.

Core's `QueryQuality` contains only `approximate`, `partial`, `sampled`, `sampleRate`,
`thresholded`, and `warnings`.
