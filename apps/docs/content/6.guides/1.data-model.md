---
title: Data model
description: Understand report kinds, metadata, and literal inference.
---

Report Sources implement only `summary`, `series`, `breakdown`, and/or `snapshot`. Their schemas
declare metrics, dimensions, History behavior, and rollup semantics once at the Provider boundary.

- `ScalarReport` contains selected metric values.
- `SeriesReport` contains timestamped points with optional dimensions.
- `TableReport` contains dimension/metric rows.

Every report carries source, query time, temporal metadata, Provider Quality, and optional
range-scoped History Fidelity. Selected metric keys propagate to the result type.

Filters use `{ field, operator, value }`; ranges use absolute ISO `from`/`to` with `[from, to)`
semantics. The SDK does not guess relative retention, initial lookback, or finalization delays.
