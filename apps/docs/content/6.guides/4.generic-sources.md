---
title: Generic Sources
description: Query logs, traces, funnels, and billing data without inventing a Core taxonomy.
---

Use a generic Source when the data is not naturally a Metric report. Core can execute heterogeneous
selections together while leaving every result shape to its Source.

```ts
const result = await insight.query((q) => ({
    funnel: q.source.product.funnel({ window: '7d' }),
    logs: q.source.observability.logs({ cursor, limit: 50 }),
    trace: q.source.observability.trace({ traceId }),
    billing: q.source.commerce.billing({ customerId }),
}))
```

Build application-local presentation for those Source shapes. Add a public helper or UI component
only after a real Provider contract has stabilized.
