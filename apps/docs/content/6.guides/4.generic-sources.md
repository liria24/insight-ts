---
title: Generic Sources
description: Model domain data without adding a Core ontology.
---

Funnel, logs, traces, and billing can use the same execution API while preserving unrelated data:

```ts
const result = await insight.query((q) => ({
    funnel: q.source('product.funnel', { window: '7d' }),
    logs: q.source('observability.logs', { cursor, limit: 50 }),
    trace: q.source('observability.trace', { traceId }),
    billing: q.source('commerce.billing', { customerId }),
}))
```

Core needs no Source kind or exhaustive union. Add a dedicated public helper or renderer only when
a real Provider contract is stable enough to justify it.
