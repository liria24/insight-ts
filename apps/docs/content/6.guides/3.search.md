---
title: Search metrics
description: Query Search Console while retaining top-row, freshness, and Pacific-calendar constraints.
---

Use a single Search Analytics Source selection for the dimensions and Metrics your view displays.

```ts
const result = await insight.query((q) => ({
    search: q.source.googleSearchConsole.searchAnalytics({
        dimensions: ['query', 'country'],
        limit: 100,
        metrics: ['clicks', 'impressions', 'ctr'],
        time: range,
        where: { page: { contains: '/docs' } },
    }),
}))
```

The Provider translates supported typed filters into Google's native AND filter groups and fetches
native pages until the requested limit is reached.

::warning
Search Analytics reports top rows rather than a complete matching row set. Show the quality warning
with the view and do not silently roll up `averagePosition`.
::
