---
title: Search reports
description: Query Search Console without translating away native semantics.
---

```ts
const search = insight.reports('googleSearchConsole.searchAnalytics')
const report = await search.breakdown({
    metrics: ['clicks', 'impressions', 'ctr'],
    dimensions: ['query', 'country'],
    range,
    limit: 100,
})
```

Search Console dimensions, filter support, data state, timezone, and provider limits are validated
before network I/O. CTR is derived from clicks/impressions during safe History rollups;
`averagePosition` remains non-additive.
