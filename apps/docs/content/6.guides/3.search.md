---
title: Search metrics
description: Query Search Console without translating away native semantics.
---

```ts
const result = await insight.query((q) => ({
    search: q.source('googleSearchConsole.searchAnalytics', {
        dimensions: ['query', 'country'],
        limit: 100,
        metrics: ['clicks', 'impressions', 'ctr'],
        time: range,
        where: { page: { contains: '/docs' } },
    }),
}))
```

The Provider maps the typed filter to Google's native dimension filter groups and paginates in
native pages. Top-row limits, incomplete data, and Pacific calendar boundaries stay visible.
