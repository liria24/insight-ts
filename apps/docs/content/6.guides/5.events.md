---
title: Events
description: Type event names and properties without standardizing provider transport.
---

```ts
const insight = createInsight({
    events: { signup: { properties: { plan: ['free', 'pro'] } } },
    providers,
})

await insight.track('signup', { plan: 'pro' })
```

Providers own their event transport. Insight.ts unifies the application event name/property
contract, not identity, consent, sessions, attribution, batching, or retry semantics.

When the optional OpenTelemetry adapter is active, the current trace and span IDs are linked to the
server-created event. Baggage and event properties are never copied into span attributes.

For same-origin browser delivery:

```ts
import { createBrowserInsight } from 'insight-ts/browser'
const browser = createBrowserInsight<{ signup: { plan: string } }>()
browser.track('signup', { plan: 'pro' })
```

The receiving host must validate the trust boundary and generate authoritative IDs, timestamps,
and origin on the server.
