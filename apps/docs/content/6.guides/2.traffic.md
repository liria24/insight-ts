---
title: Traffic metrics
description: Query Cloudflare page views, visits, and application-owned recent activity.
---

```ts
const dashboard = await insight.query((q) => ({
    series: q.source('cloudflare.webAnalytics', {
        metrics: ['pageViews', 'visits'],
        time: { ...range, grain: 'day' },
    }),
    pages: q.source('cloudflare.webAnalytics', {
        dimensions: ['path'],
        limit: 20,
        metrics: ['pageViews'],
        time: range,
    }),
    recent: q.source('cloudflare.webAnalytics', {
        metrics: ['visits'],
        time: recentFiveMinutes,
    }),
}))
const online = Math.round(dashboard.recent.data.visits.value ?? 0)
```

`online` is application-owned; it is not a native active-user metric and is not stored or rolled
up as one. Sampling and partiality remain in each result's `QueryQuality`.
