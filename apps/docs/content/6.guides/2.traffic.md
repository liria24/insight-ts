---
title: Traffic reports
description: Query Cloudflare page views, visits, and current activity.
---

```ts
const traffic = insight.reports('cloudflare.webAnalytics')
const series = await traffic.series({
    metrics: ['pageViews', 'visits'],
    grain: 'day',
    range,
})
const summary = await traffic.summary({ metrics: ['pageViews', 'visits'], range })
```

Web Analytics may omit dates with no returned bucket. This is normal provider behavior; Insight.ts
does not invent a zero. `InsightLineChart` and `InsightAreaChart` use a numeric time domain, so
August 27 → August 31 is visibly wider than a one-day interval.

`activeUsers` is a current five-minute approximation. Treat it independently from additive
`pageViews` and `visits` and do not include it in History rollups.
