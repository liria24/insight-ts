---
title: History
description: Preserve canonical Metrics, Logs, and Traces beyond Provider retention.
---

Use History when native Provider retention or fidelity is shorter than the range your product
needs. The same workflow preserves any configured canonical capability that declares a
materializer. Missing or provisional intervals are filled through normal Provider execution.

```ts
import { createHistory } from 'insight-ts/history'

const insight = createInsight({
    providers,
    history: createHistory({
        repository,
        capabilities: ['metrics', 'logs', 'traces'],
        // Optional when all configured Scopes should be preserved.
        scopes: ['production'],
    }),
})

await insight.history.sync({
    range: { from: '2026-01-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

Omit `capabilities` and `scopes` to enable every materializable adapter. `sync()` accepts the same
optional selection to narrow one run without exposing Provider adapter IDs.

## Materialization and pagination

Canonical capability adapters own data-specific capture and reconstruction. Metrics retain safe
aggregation and ratio rules; Logs and Traces retain stable IDs and ordering. History drains every
native continuation before marking a range complete. Later event-like queries use bounded
repository reads and the normal `meta.pagination.next` cursor.

The Engine owns gap slicing, deterministic identity, reduction policies, range-scoped Fidelity,
and lifecycle. A repository implements `coverage`, bounded `read`, `replace`, and `delete`.

## Fidelity and lifecycle

An empty full-fidelity segment means the completed range had no matching data. Reduced segments
list sampling, filtering, truncation, or custom transformations. Missing or provisional coverage
is `not-preserved` and also reports partial Quality; it is never presented as an authoritative
empty result.

Use `insight.history.compact({ range })` to replace duplicate retained segments and
`insight.history.expire({ before })` to delete aged ranges. `retention.maxAgeMs` can supply the
default expiration boundary.

::caution
History is not a cache. Queries a capability materializer cannot represent execute live. Unsafe
percentiles and other non-additive values are rejected instead of being silently combined. A
repository may compress losslessly but must never apply hidden reduction.
::
