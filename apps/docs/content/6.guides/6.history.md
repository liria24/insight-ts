---
title: History
description: Backfill range sources and capture snapshots without exposing storage planning.
---

Providers own schema, query semantics, grain, safe rollups, freshness, and History declarations.
The History Engine owns coverage, gaps, Provider fetches, composition, reduction, and idempotent
segment writes. A repository implements only `coverage`, `read`, and `write`.

```ts
import { createInsight } from 'insight-ts'
import { createHistory } from 'insight-ts/history'

const insight = createInsight({
    providers,
    history: createHistory({
        repository,
        sources: ['commerce.orders'],
    }),
})

await insight.history.sync({
    range: { from: '2026-01-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

Range sync fetches only missing or provisional intervals. Snapshot sources use
`await insight.history.capture()` and History later supplies their series.

Lossy reductions (`sample`, `filter`, `omit-fields`, `truncate`, `aggregate`, or `custom`) run in
the Engine. Each segment records `HistoryFidelity`; range-scoped Fidelity reaches query results
without being merged into Provider `ReportQuality`. Repositories may apply lossless compression,
but must never silently reduce data.
