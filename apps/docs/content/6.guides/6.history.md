---
title: History
description: Backfill Metric Sources through normal query execution.
---

The current History implementation is an optional Metric Source strategy:

```ts
const insight = createInsight({
    providers,
    history: createHistory({ repository, sources: ['cloudflare.webAnalytics'] }),
})
await insight.history.sync({
    range: { from: '2026-01-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

Sync asks the repository for coverage, finds missing or provisional intervals, and fetches all
planned slices through normal multi-query execution. Segment identity is deterministic.

The Source declares stored metrics, safe dimensions, grain, aggregation, and rollup. The Engine
owns composition, ratio recomputation, reduction, range-scoped Fidelity, and idempotency. A
repository only implements `coverage`, `read`, and `write`.

Percentiles and other non-additive values are rejected when a safe rollup cannot be proven.
Filtered queries not represented by History execute live. Repositories may compress losslessly but
never apply silent reduction. History is not a persistent response cache.
