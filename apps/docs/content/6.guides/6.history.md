---
title: History
description: Backfill Source-declared Metric ranges through normal query execution.
---

Use History when a Metric Source defines safe materialization and native retention is shorter than
the range your product needs. It fills missing or provisional intervals through normal Source
execution.

```ts
import { createHistory } from 'insight-ts/history'

const insight = createInsight({
    providers,
    history: createHistory({
        repository,
        sources: ['cloudflare.webAnalytics'],
    }),
})

await insight.history.sync({
    range: { from: '2026-01-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

## What gets stored

The Source declares stored Metrics, safe dimensions, grain, aggregation, and rollup. The Engine
owns coverage, gap slicing, composition, ratio recomputation, reduction, range-scoped Fidelity,
and idempotent segment identity. A repository implements only `coverage`, `read`, and `write`.

::caution
History is not a cache. Unsupported filters execute live; unsafe percentiles and other non-additive
values are rejected instead of being silently combined. A repository may compress losslessly but
must never apply hidden reduction.
::
