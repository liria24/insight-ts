---
title: Custom providers
description: Define provider-independent Sources without implementing Core adapter internals.
---

`defineAnalyticsProvider()` is the supported extension point for application and third-party
Providers. A Provider has a stable ID, one or more Sources, and an optional event destination.

```ts
import { createAnalytics } from '@liria24/analytics'
import { defineAnalyticsProvider } from '@liria24/analytics/provider'

const commerce = defineAnalyticsProvider({
    id: 'custom',
    sources: [
        {
            id: 'custom.orders',
            domain: 'commerce',
            metrics: {
                orders: {
                    aggregation: 'sum',
                    rollup: 'additive',
                    valueType: 'integer',
                },
            },
            dimensions: {
                time: { valueType: 'datetime' },
            },
            archive: {
                materializations: [
                    {
                        id: 'daily-orders',
                        grain: 'day',
                        dimensions: ['time'],
                        metrics: ['orders'],
                    },
                ],
                finalizationDelay: '1d',
                initialLookback: '6m',
            },
            async query(query, context) {
                const rows = await fetchOrders(query.range.from, query.range.to)
                return context.series({
                    points: rows.map((row) => ({
                        time: row.time,
                        values: { orders: row.orders },
                    })),
                })
            },
        },
    ],
})

const analytics = createAnalytics({ name: 'shop', providers: [commerce] })
```

Metric and dimension descriptors use object maps so literal keys remain available for future type
inference. The report factory fills `source`, `queriedAt`, grain, timezone, and empty quality
metadata. Provider code supplies only points or values plus any real quality and freshness facts.

Query a custom domain or pin one Source:

```ts
await analytics.domain('commerce').series({ metrics: ['orders'], grain: 'day', range })
await analytics.source('custom.orders').series({ metrics: ['orders'], grain: 'day', range })
```

In Nuxt, put stable resource declarations in `nuxt.config.ts` and request-scoped Provider factories
in `server/analytics.config.ts` through `customProviders: ({ event }) => [...]`.
