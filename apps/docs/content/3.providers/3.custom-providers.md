---
title: Custom Providers
description: Define a typed Provider with inferred source, metric, and operation keys.
---

`defineProvider()` is the extension API. Source IDs are derived once as
`<provider>.<report-key>`:

```ts
import { createInsight } from 'insight-ts'
import { defineProvider } from 'insight-ts/provider'

const commerce = defineProvider({
    id: 'commerce',
    reports: {
        orders: {
            metrics: {
                orders: { valueType: 'integer', aggregation: 'sum', rollup: 'additive' },
                revenue: 'currency',
            },
            dimensions: { time: 'datetime' },
            history: { mode: 'range', grain: 'day' },
            async series({ range }) {
                return { points: await loadOrders(range) }
            },
        },
    },
})

const insight = createInsight({ providers: [commerce] })
const report = await insight.reports('commerce.orders').series({
    metrics: ['orders'],
    range: { from: '2026-08-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

The Provider ID, Report Source ID, selected metric, dimension, and implemented operation remain
literal types. Shorthand metric definitions state only the value type; Insight.ts does not guess
aggregation or rollup semantics.

Use `snapshot()` with `history: { mode: 'snapshot' }` for values available only “now”. Do not
model a custom Provider as a special product or state domain.
