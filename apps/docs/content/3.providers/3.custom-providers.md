---
title: Custom Providers
description: Define arbitrary typed Sources without changing Core.
---

```ts
import { defineProvider, defineSource } from 'insight-ts/provider'

const logs = defineSource({
    normalize: (query: { cursor?: string }) => ({ cursor: query.cursor ?? '' }),
    key: ({ cursor }) => cursor,
    execute: async ({ cursor }, { signal }) => ({
        data: await loadLogs({ cursor, signal }),
        meta: { nextCursor: cursor || 'page-2' },
    }),
})
const provider = defineProvider({ id: 'app', sources: { logs } })
const insight = createInsight({ providers: [provider] as const })
const data = await insight.query((q) => ({ logs: q.source('app.logs', {}) }))
```

`normalize()` is pure and deterministic. `key()` owns exact semantic dedupe. Core constructs the
envelope and never interprets cursors or entries. Use `defineMetricSource()` only when Metric
selection, dimensions, filters, and rollup genuinely fit.
