---
title: Cloudflare
description: Query Web Analytics Metrics and use Analytics Engine independently.
---

Cloudflare contributes independent Sources and event delivery. Provider implementations never
fall back to simulated data; applications explicitly select demo Sources when native data is
unavailable.

```ts
const dashboard = await insight.query((q) => ({
    traffic: q.source('cloudflare.webAnalytics', {
        dimensions: ['path'],
        limit: 20,
        metrics: ['pageViews', 'visits'],
        time: { ...range, grain: 'day' },
        where: { country: { in: ['JP', 'US'] } },
    }),
}))
```

Breakdowns include pages, referrers, countries, devices, browsers, hosts, and operating systems.
Sampling becomes `sampled`, `sampleRate`, and `approximate`; row limits remain partial warnings.

There is no native `activeUsers` metric. The demo's `online` value is an application KPI built by
querying `visits` over the latest five minutes as a separate Source selection.

`cloudflareAnalyticsEngine()` may expose a narrow Metric Source, a Worker-binding event
destination, or both. Dataset names and SQL constraints remain native.
