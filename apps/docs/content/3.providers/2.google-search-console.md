---
title: Google Search Console
description: Query typed Search Analytics Metrics with native pagination.
---

```ts
const provider = googleSearchConsole({
    auth: { getAccessToken },
    property: 'sc-domain:example.com',
})
const insight = createInsight({ providers: [provider] as const })
const result = await insight.query((q) => ({
    search: q.source('googleSearchConsole.searchAnalytics', {
        dimensions: ['query', 'page'],
        metrics: ['clicks', 'impressions', 'ctr', 'averagePosition'],
        time: range,
        where: { page: { contains: '/docs' } },
    }),
}))
```

The host owns token acquisition. Insight.ts stores no OAuth credentials and creates no auth routes.
Pagination, top-row partiality, incomplete dates, and Pacific calendar boundaries remain visible.
`ctr` is derived; `averagePosition` is never silently rolled up.
