---
title: Google Search Console
description: Query the typed Search Analytics Report Source.
---

```ts
import { createInsight } from 'insight-ts'
import { googleSearchConsole } from 'insight-ts/google-search-console'

const insight = createInsight({
    providers: [
        googleSearchConsole({
            property: 'sc-domain:example.com',
            auth: { getAccessToken },
        }),
    ],
})

const report = await insight.reports('googleSearchConsole.searchAnalytics').series({
    metrics: ['clicks', 'impressions', 'ctr'],
    grain: 'day',
    range: { from: '2026-08-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

Authentication remains host-owned: the Provider calls `getAccessToken()` and never stores OAuth
credentials or creates login/callback routes. Search Analytics pagination is grouped by native
requests, not rows or metrics.

History can safely sum clicks and impressions and recompute CTR. Average position is non-additive
and is never silently rolled up.
