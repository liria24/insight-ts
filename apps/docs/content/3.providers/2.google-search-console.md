---
title: Google Search Console
description: Query Search Analytics with host-owned OAuth access tokens.
---

Google Search Console reads private property data and requires OAuth 2.0. An API key alone is not
enough.

You need:

- a property such as `sc-domain:example.com` or `https://example.com/`;
- a server-only callback that returns a current access token;
- the `webmasters.readonly` or `webmasters` OAuth scope.

```ts
import { createAnalytics } from '@liria24/analytics'
import { googleSearchConsole } from '@liria24/analytics/google-search-console'

const analytics = createAnalytics({
    name: 'website',
    adapters: [
        googleSearchConsole({
            property: 'sc-domain:example.com',
            auth: {
                getAccessToken: () => getGoogleAccessTokenFromServerSecrets(),
            },
        }),
    ],
})
```

The host application owns OAuth login, refresh-token storage, and token refresh. Analytics SDK
does not store credentials, create callback routes, or require a database.

## Data finalization

Search Console can finalize data several days after collection. Initial archive maintenance can
look back up to 16 months. Completed monthly coverage continues to refresh for seven days after
the partition ends; only then is the partition sealed.

This allows delayed rows to reach the archive without repeatedly querying finalized history.

## Nuxt

Put the property identifier in `nuxt.config.ts` and keep the access-token callback in the
server-only analytics config:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['@liria24/analytics/nuxt'],
    analytics: {
        name: 'website',
        providers: {
            searchConsole: 'sc-domain:example.com',
        },
    },
})
```

```ts [server/analytics.config.ts]
import { defineNuxtAnalyticsConfig } from '@liria24/analytics/nuxt/runtime'

export default defineNuxtAnalyticsConfig({
    auth: {
        searchConsole: {
            getAccessToken: () => getGoogleAccessTokenFromServerSecrets(),
        },
    },
})
```

## Troubleshooting

Confirm the property spelling, authorized account access, OAuth scope, token expiry, and Google
API quota errors.
