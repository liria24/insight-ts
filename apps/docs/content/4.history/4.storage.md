---
title: Storage
description: Implement the small generic repository contract or use Nitro Storage.
---

A History repository implements `coverage`, bounded `read`, `replace`, and `delete`. It must
preserve exact canonical data and completed empty ranges.

The Nitro integration mounts this contract on `nitro.storage.insight` or
`nitro.devStorage.insight`. Storage keys, layouts, and cursors are private; use the public History
APIs to synchronize, query, and expire data.
