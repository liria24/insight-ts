---
title: InsightQualityNotice
description: Render cross-cutting QueryQuality warnings without hiding provider facts.
---

Use `InsightQualityNotice` when quality metadata needs a dedicated place outside another component.
Pass `result.meta.quality`; provider-specific freshness, pagination, temporal metadata, and History
Fidelity remain intentionally separate.

## Example

::code-preview
:::insight-quality-notice{:data='{"approximate":true,"sampled":true,"sampleRate":0.25}'}
:::

#code

```vue
<InsightQualityNotice :data="{ approximate: true, sampled: true, sampleRate: 0.25 }" />
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightQualityNotice } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightQualityNotice :data="dashboard.trafficSeries.meta.quality" />
</template>
```

It renders `approximate`, `partial`, `sampled`, `sampleRate`, `thresholded`, and custom `warnings`.
When `data` is absent or contains no notices, it renders nothing.

## Props

| Prop    | Type                     | Default   |
| ------- | ------------------------ | --------- |
| `data`  | `QueryQuality`           | —         |
| `class` | class value              | root only |
| `ui`    | `InsightQualityNoticeUI` | —         |

## Customization

```vue
<InsightQualityNotice
    class="rounded-lg border border-warning/30 bg-warning/10 p-3 text-sm"
    :data="result.meta.quality"
    :ui="{ item: 'marker:text-warning', list: 'space-y-1' }"
/>
```

| `ui` key | `data-slot` | Element           |
| -------- | ----------- | ----------------- |
| `root`   | `root`      | `<aside>`         |
| `list`   | `list`      | notice list       |
| `item`   | `item`      | individual notice |

The notice inherits `--insight-text`. It has no formatter: quality messages are created from the
shared `QueryQuality` contract, while an application can replace the component when it needs its
own message policy.
