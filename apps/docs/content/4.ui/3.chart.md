---
title: InsightChart
description: Render selected Metric series as a Line, Area, or grouped Bar chart.
---

Use `InsightChart` for time-series metrics selected together by one Metrics query. `type`
chooses `line`, `area`, or `bar`; Line is the default.

## Example

::code-preview
:::insight-chart{:data='{"aggregate":{"pageViews":4140,"visits":2900},"rows":[{"time":"2026-08-26T00:00:00.000Z","values":{"pageViews":1240,"visits":820}},{"time":"2026-08-27T00:00:00.000Z","values":{"pageViews":1510,"visits":1080}},{"time":"2026-08-28T00:00:00.000Z","values":{"pageViews":1390,"visits":1000}}],"meta":{"queriedAt":"2026-08-28T09:00:00.000Z"}}' :height="240" title="Traffic" type="bar"}
:::

#code

```vue
<InsightChart
    :data="{
        aggregate: { pageViews: 4140, visits: 2900 },
        meta: { queriedAt: '2026-08-28T09:00:00.000Z' },
        rows: [
            {
                time: '2026-08-26T00:00:00.000Z',
                values: { pageViews: 1240, visits: 820 },
            },
            {
                time: '2026-08-27T00:00:00.000Z',
                values: { pageViews: 1510, visits: 1080 },
            },
            {
                time: '2026-08-28T00:00:00.000Z',
                values: { pageViews: 1390, visits: 1000 },
            },
        ],
    }"
    :height="240"
    title="Traffic"
    type="bar"
/>
```

::

## Usage

```vue
<script setup lang="ts">
import { InsightChart } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightChart :data="dashboard.trafficSeries" title="Traffic" />
    <InsightChart :data="dashboard.trafficSeries" title="Traffic volume" type="area" />
    <InsightChart :data="dashboard.trafficSeries" title="Traffic by day" type="bar" />
</template>
```

Line uses proportional time spacing. Area overlays unstacked series. Bar treats each returned time
as an ordered category, groups multiple Metrics side by side, and includes zero in its default Y
domain. Use [InsightBarList](/ui/bar-list) for a compact dimension ranking.

Metric selection belongs to the query. The chart has no `metrics` prop and does not aggregate,
fetch, or reorder the selected results.

## Props

| Prop       | Type                                   | Default                        |
| ---------- | -------------------------------------- | ------------------------------ |
| `data`     | Metric `QueryResult` with time rows    | required                       |
| `type`     | `line \| area \| bar`                  | `line`                         |
| `title`    | `string`                               | —                              |
| `height`   | `number`                               | `360`                          |
| `colors`   | `readonly string[]`                    | six `--insight-chart-*` colors |
| `smooth`   | `boolean`                              | `false`                        |
| `locale`   | `string`                               | `en-US`                        |
| `timezone` | `local`, `source`, `utc`, or IANA zone | local                          |
| `xAxis`    | `XAxisOptions`                         | —                              |
| `yAxis`    | `YAxisOptions`                         | —                              |
| `class`    | class value                            | root only                      |
| `ui`       | `InsightChartUI`                       | —                              |

## Customization

```vue
<InsightChart
    :data="dashboard.trafficSeries"
    title="Traffic"
    type="area"
    :x-axis="{ maxTicks: 4, formatter: (date) => date.toLocaleDateString() }"
    :y-axis="{ formatter: (value) => `${value.toLocaleString()} visits` }"
    :ui="{ legend: 'text-xs', plot: 'rounded-lg bg-muted/30 p-3' }"
/>
```

| `ui` key          | `data-slot`        | Element                  |
| ----------------- | ------------------ | ------------------------ |
| `root`            | `root`             | chart section            |
| `header`          | `header`           | title and legend wrapper |
| `title`           | `title`            | heading                  |
| `plot`            | `plot`             | chart                    |
| `legend`          | `legend`           | series list              |
| `legendItem`      | `legend-item`      | series item              |
| `legendIndicator` | `legend-indicator` | color marker             |
| `tooltip`         | `tooltip`          | tooltip panel            |
| `tooltipLabel`    | `tooltip-label`    | tooltip time label       |
| `tooltipItem`     | `tooltip-item`     | tooltip series value     |
| `notices`         | `notices`          | quality message          |
| `empty`           | `empty`            | empty state              |

The chart inherits `--insight-text`, `--insight-text-muted`, `--insight-text-highlighted`,
`--insight-border`, `--insight-background`, `--insight-chart-axis`, `--insight-chart-grid`,
and `--insight-chart-1` through `--insight-chart-6`.

`xAxis.formatter` receives a `Date`; `yAxis.formatter` receives a number. `colors` changes
series colors without exposing the private renderer.

Charts bound rendered geometry for large results without changing `data`. The exact values remain
available through the chart's semantic data table; when that table would be very large, the chart
mounts it after the user chooses **Show exact data**.

## Slots

| Slot      | Receives                         | Replaces        |
| --------- | -------------------------------- | --------------- |
| `title`   | `{ title }`                      | title markup    |
| `legend`  | `{ series }`                     | legend markup   |
| `tooltip` | `{ label, point, values }`       | tooltip markup  |
| `notices` | `{ messages, notices, quality }` | quality message |
| `empty`   | `{ message }`                    | empty state     |
