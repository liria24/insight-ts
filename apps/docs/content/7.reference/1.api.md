| Entrypoint                         | Purpose                                                               |
| ---------------------------------- | --------------------------------------------------------------------- |
| `insight-ts`                       | `createInsight`, generic Source execution, events, errors, Core types |
| `insight-ts/provider`              | `defineSource`, `defineProvider`                                      |
| `insight-ts/metrics`               | Metric definitions, structured aggregation, typed filters             |
| `insight-ts/history`               | Metric History Engine and three-method repository                     |
| `insight-ts/opentelemetry`         | Optional adapter for host-owned OTel API                              |
| `insight-ts/cloudflare`            | Cloudflare Sources and event destination                              |
| `insight-ts/google-search-console` | Search Console Metric Source                                          |
| `insight-ts/browser`               | Bounded browser event client                                          |
| `insight-ts/ui-core`               | Framework/DOM/renderer-independent Metric models                      |
| `insight-ts/nitro`                 | Nitro Storage repository and optional sync task                       |
| `insight-ts/nuxt`                  | Nuxt configuration and server wiring                                  |
| `insight-ts/vue`                   | Vue browser provide/inject                                            |
| `insight-ts/vue/ui`                | Vue Metric components, CSS, private chart renderer                    |

```ts
insight.query(
    (q) => ({
        traffic: q.source('cloudflare.webAnalytics', trafficQuery),
        logs: q.source('app.logs', logsQuery),
    }),
    { signal },
)
insight.sources()
insight.track('signup', { plan: 'pro' })
```

Source IDs derive from Provider ID and source key. `InsightError` identifies shared failures;
Provider-native failures extend `ProviderError` with status, retryability, and native codes.

The OpenTelemetry adapter instruments `insight.query`, `insight.provider.execute`,
`insight.event.track`, and History operations with safe `insight.*` attributes. Hosts own SDKs,
exporters, Collectors, and baggage.
