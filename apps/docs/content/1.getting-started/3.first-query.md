---
title: First query
description: Configure a Provider and request a typed series report.
---

```ts
import { createInsight } from 'insight-ts'
import { cloudflareWebAnalytics } from 'insight-ts/cloudflare'
import { defineProvider } from 'insight-ts/provider'

const cloudflare = defineProvider({
    id: 'cloudflare',
    reports: {
        webAnalytics: cloudflareWebAnalytics({
            accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
            apiToken: process.env.CLOUDFLARE_API_TOKEN!,
            siteTag: process.env.CLOUDFLARE_SITE_TAG!,
        }),
    },
})
const insight = createInsight({ providers: [cloudflare] })

const report = await insight.reports('cloudflare.webAnalytics').series({
    metrics: ['pageViews', 'visits'],
    grain: 'day',
    range: { from: '2026-08-01T00:00:00.000Z', to: '2026-09-01T00:00:00.000Z' },
})
```

The range is absolute and half-open: `[from, to)`. Misspelled Source IDs, metrics, and unsupported
operations fail at compile time when the Provider definition is known. Shared validation runs
before provider network I/O.
