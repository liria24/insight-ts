---
title: First query
description: Configure a provider and request typed analytics reports from one Source.
---

Create one analytics instance with an explicit project name and one or more providers:

```ts
import { createAnalytics } from '@liria24/analytics'
import { cloudflare } from '@liria24/analytics/cloudflare'

const analytics = createAnalytics({
    name: 'website',
    providers: [
        cloudflare({
            accountId: process.env.CLOUDFLARE_ACCOUNT_ID!,
            apiToken: process.env.CLOUDFLARE_API_TOKEN!,
            webAnalytics: { siteTag: process.env.CLOUDFLARE_SITE_TAG! },
        }),
    ],
})
```

Query a daily traffic series:

```ts
const range = {
    from: '2026-08-01T00:00:00.000Z',
    to: '2026-08-31T00:00:00.000Z',
}

const report = await analytics.traffic.series({
    grain: 'day',
    metrics: ['pageViews', 'visits'],
    range,
})
```

The result is a provider-independent series report:

```ts
report.kind
report.points
report.meta.source
report.meta.quality
report.meta.freshness
```

The Provider preserves facts such as sampling and incomplete coverage in
`report.meta`. Your application can render, cache, or store the report without depending on a
provider-native response shape.

## Multiple providers

Give each configured Source a unique ID. When more than one compatible Source exists,
select one in the query or configure a domain default:

```ts
const report = await analytics.source('cloudflare.web-analytics').summary({
    metrics: ['pageViews'],
    range,
})
```

Analytics SDK never chooses the first configured provider and never silently merges totals from
different providers.
