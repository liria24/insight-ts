---
title: First query
description: Configure a Provider and lazily select typed Sources.
---

```ts
import { createInsight } from 'insight-ts'
import { cloudflareWebAnalytics } from 'insight-ts/cloudflare'
import { defineProvider } from 'insight-ts/provider'

const cloudflare = defineProvider({
    id: 'cloudflare',
    sources: { webAnalytics: cloudflareWebAnalytics({ accountId, apiToken, siteTag }) },
})
const insight = createInsight({ providers: [cloudflare] as const })
const dashboard = await insight.query((q) => ({
    traffic: q.source('cloudflare.webAnalytics', {
        metrics: ['pageViews', 'visits'],
        time: {
            from: '2026-08-01T00:00:00.000Z',
            grain: 'day',
            to: '2026-08-08T00:00:00.000Z',
        },
        where: { country: { in: ['JP', 'US'] } },
    }),
}))
```

The callback creates descriptors; I/O begins after it returns, allowing normalization, dedupe,
and Provider grouping. Cancellation is an execution concern:

```ts
await insight.query((q) => ({ traffic: q.source('cloudflare.webAnalytics', query) }), {
    signal: request.signal,
})
```
