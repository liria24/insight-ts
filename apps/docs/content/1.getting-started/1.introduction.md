title: Introduction
description: Query analytics, observability, and application data with typed, provider-aware Sources.
---

Insight.ts is a TypeScript SDK for querying data from services and application code without making
them pretend to be the same product. You select explicit Sources, receive typed results, and keep
each Provider's metrics, limits, sampling, and metadata visible.

```ts
const dashboard = await insight.query((q) => ({
    traffic: q.source.cloudflare.webAnalytics(trafficQuery),
    logs: q.source.observability.logs({ limit: 20 }),
    billing: q.source.commerce.billing({ customer: 'acme' }),
}))
```

Start with one Source. Add Metric helpers, History, events, or UI only when your application needs
them.

::tip
A Source selection is always explicit through `q.source.<providerAccessor>.<sourceKey>`. Its
canonical internal ID remains `provider-id.sourceKey`, so unrelated Provider totals are never
silently combined.
::
