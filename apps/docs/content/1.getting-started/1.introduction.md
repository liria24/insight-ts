title: Introduction
description: Typed Source queries across analytics, observability, and application data.
---

Insight.ts is a runtime-neutral TypeScript SDK for heterogeneous data Sources. Core does not force
analytics, observability, product, logs, traces, funnels, or billing into one ontology.

Every Source owns its query, normalization, exact dedupe key, data, and metadata. Core owns lazy
selection, Provider grouping, bounded execution, abort, and the `QueryResult` envelope.

```ts
const dashboard = await insight.query((q) => ({
    traffic: q.source('cloudflare.webAnalytics', trafficQuery),
    logs: q.source('observability.logs', { limit: 20 }),
    billing: q.source('commerce.billing', { customer: 'acme' }),
}))
```

`insight-ts/metrics` optionally adds structured Metric aggregation, safe rollup, and a typed object
filter DSL. OpenTelemetry is the observability interoperability standard through an optional
adapter, not the universal Insight.ts data model.
