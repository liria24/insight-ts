Analytics SDK gives TypeScript applications one query and report model across analytics
providers. It is a library you compose into your server, not a hosted analytics service and not a
Nuxt-only module.

Use the core package to:

- query traffic, search, product, experience, or application-state data;
- keep source, freshness, sampling, approximation, and partial-result metadata;
- materialize supported history in any [unstorage](https://unstorage.unjs.io)-compatible store;
- define typed application events without standardizing provider-owned identity or sessions.

Cloudflare Web Analytics, Cloudflare Analytics Engine, and Google Search Console are currently
implemented. Each Provider Source validates its own metrics, dimensions, filters, ranges, and native
limits before making a request.

## Optional integrations

The core API has no Nuxt, Nitro, H3, or Vue dependency.

- Add the [Nuxt integration](/integrations/nuxt) when Nuxt should resolve bindings, storage,
  browser relays, or maintenance tasks.
- Add the [Vue integration](/integrations/vue) when you want small report-only presentation
  primitives.

Neither integration changes the query and report contracts.

## Start here

Install the package, configure one Provider, and run your [first query](/getting-started/first-query).
