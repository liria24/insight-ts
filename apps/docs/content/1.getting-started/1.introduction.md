Insight.ts is a TypeScript SDK for querying Providers through optional capabilities while
preserving provider-specific semantics. It favors literal inference, short application code, and
runtime-native integrations.

Providers expose only real operations. Report Source IDs, metrics, dimensions, and selected
result keys are inferred from configured Providers. Custom Providers use the same contract as
built-ins.

History backfills missing ranges or captures snapshots behind a three-method repository.
`ui-core` creates framework-neutral models. Nitro, Nuxt, Vue, and Vue UI remain independently
optional, so unused Provider, History, Integration, and renderer code can be tree-shaken.
