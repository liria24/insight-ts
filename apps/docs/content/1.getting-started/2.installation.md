---
title: Installation
description: Install Insight.ts and only the host integrations you use.
---

```bash
bun add insight-ts
```

The package is MIT licensed. TanStack Charts is reachable only from `insight-ts/vue/ui`.
`@opentelemetry/api` is an optional peer reached only through `insight-ts/opentelemetry`; Core has
no OpenTelemetry runtime dependency.

```ts
import { createInsight } from 'insight-ts'
import { defineProvider } from 'insight-ts/provider'
```

For Nuxt:

```ts
export default defineNuxtConfig({ modules: ['insight-ts/nuxt'] })
```

For optional Vue report UI, Vue 3.5 or newer is supported:

```ts
import { InsightAreaChart } from 'insight-ts/vue/ui'
```

The UI stylesheet loads through that entry automatically.
