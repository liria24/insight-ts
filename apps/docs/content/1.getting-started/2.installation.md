---
title: Installation
description: Install the core package and only the optional integrations you use.
---

Install the package with your package manager:

::code-group

```bash [npm]
npm install @liria24/analytics
```

```bash [pnpm]
pnpm add @liria24/analytics
```

```bash [bun]
bun add @liria24/analytics
```

::

The core entry includes the shared query, report, configuration, and error types. Provider and
framework code is available through explicit subpath imports, so your application only loads what
it imports.

```ts
import { createAnalytics } from '@liria24/analytics'
import { cloudflareWebAnalytics } from '@liria24/analytics/cloudflare'
```

## Runtime requirements

Run provider queries on the server. API tokens and OAuth access tokens must stay in server secrets
and must not be included in browser bundles or public runtime configuration.

Optional integrations have their own peer dependencies:

```bash
bun add vue vue-data-ui
```

Nuxt applications already provide Nuxt, Vue, H3, and Nitro. See the [Nuxt integration
guide](/integrations/nuxt) before adding the module.
