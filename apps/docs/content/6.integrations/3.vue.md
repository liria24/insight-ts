Vue has two distinct entrypoints. `insight-ts/vue` provides an existing browser event client through
Vue injection. `insight-ts/vue/ui` renders existing Metric results. Neither entry creates Providers,
queries server data, or configures a relay.

## Browser event client

```vue
<script setup lang="ts">
import { createBrowserInsight } from 'insight-ts/browser'
import { provideBrowserInsight, useBrowserInsight } from 'insight-ts/vue'

const browserInsight = createBrowserInsight<{ signup: { plan: string } }>()
provideBrowserInsight(browserInsight)

const insight = useBrowserInsight<{ signup: { plan: string } }>()
insight.track('signup', { plan: 'pro' })
</script>
```

`insight-ts/browser` batches same-origin delivery. The receiving server owns event validation and
must create authoritative IDs, timestamps, and origin.

## Metric UI

```vue
<script setup lang="ts">
import { InsightAreaChart, InsightStat } from 'insight-ts/vue/ui'
</script>

<template>
    <InsightStat :data="dashboard.pageViews" />
    <InsightAreaChart :data="dashboard.trafficSeries" title="Traffic" />
</template>
```

Every data-bearing UI prop is named `data`. Line and area charts render every selected Metric in
Source order. Stat, Sparkline, and BarChart derive their one Metric from a single-metric result.

::note
Importing `insight-ts/vue/ui` loads its base CSS. You can also import
`insight-ts/vue/ui/style.css` directly as an escape hatch.
::
