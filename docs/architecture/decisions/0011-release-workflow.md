# 0011: Release workflow

Status: accepted

## Decision

Releases use uppt pinned to the immutable v0.6.9 commit. Manual dispatch accepts `prerelease` and
`npm-tag`. Release versions, branches, tags, and npm dist-tags are generated by uppt; package
versions are not edited manually on main.

## Consequences

Alpha progression is `0.0.1-alpha.0`, subsequent alpha versions, then `0.0.1`. CI and package
preview must run on the generated Release PR before merge. Workflow actions stay commit-pinned.
